# 交接 11 结果：每个人的选择都不一样（Claude 实现，2026-10-23）

> Codex 额度用尽，用户「他又没额度了，你来」，由 Claude 实现。开工前工作区备份在 Claude 临时目录（toutai-before-11.tgz）。

## 做了什么

1. **引擎（`src/engine/cards.js`）**：卡片支持 `variants`。按处境**确定性**地挑第一个匹配的版本，替换标题、情境和选项文字；**选项编号和后果不变，不消耗随机数**。
   pending 和 `cardHistory` 记下 `variant`，探针按「卡 + 版本」统计。
2. **变体内容**（三个文件，合并在 `src/content/cards/index.js`）：
   - `variants.js`：分组尺子 + 12 张关键卡（2 岁、中考、没考上公办、高考、毕业去向、选城市、结婚、买房、35 岁、父母遗产、回老家、婚姻危机）；
   - `variants-more.js`：29 张（童年天分、竞赛、初恋、学费、专业、晋升、调薪、中年退路、生孩子、二胎、谁带孩子、陪孩子中考高考、帮孩子付首付、照顾父母、分家、退休、带孙辈、养老住处、遗嘱、晚年四张、个体户社保、复读、专升本、兄弟姐妹借钱）；
   - `variant-labels.js`：给只换了标题的变体补上按处境写的选项文字。
   共 **41 张卡**带变体，每张 4–5 个版本，标题互不相同，≥90% 的版本换了选项文字。
3. **分组尺子**（每组都不超过约 40%）：
   童年出身（留守 / 农村 / 城市低收入 / 城市中等 / 城市富裕）、成年处境（名校或富裕 / 普通本科 / 农村出身打工者 / 城镇工薪）、
   性别 × 城乡、晚年（体制内 / 住在村里 / 本科以上 / 城镇工薪，按**现在住在哪**而不是户口）、退休（按**实际交的养老保险**：机关事业 / 职工本科 / 职工其他 / 没交满 20 年）。
4. **富豪线**：8 张 `rich-*` 卡原来要和大量卡按权重竞争，出生中约 0.2% 的富家孩子一张都遇不到 → 给优先级，到年龄窗口就出现。60 个富家孩子里每张出现 92–98%。

## 对照：同一套系统下的两种人生

**农村 Q1 留守（粤-2026-694669）**：奶奶灶台边的一声响 → 中考志愿，是打电话填的 → 毕业以后去哪挣钱 → 车间要选一个拉长 → 过年回家，媒人上门了 →
县城的房子，还是村里盖房 → 计件单价又降了 → 厂里不再招 35 岁以上的人 → 电话里问孩子的中考 → 老屋、宅基地和那几亩地 → 公园里常遇见的那个人

**城市 Q5（京-2026-066321）**：早教课上的积木塔 → 画室老师说可以走艺术路线 → 竞赛教练的一对一课 → 升学顾问给的三条路 → 学费从来不是问题 →
三十岁前后的那场相亲 → 结婚得有套房 → 单位效益不好了 → 家里的资产，比你知道的多 → 去医院挂号要用手机了

## 留给以后
