## A. 引擎：出身梯度不对（P0）

Claude 探针（6 万局，活到 18 岁以上，按 档位×户口×家境 分层）：

| 分组 | 本科率 |
|---|---|
| 全国 城市 Q1 / Q3 / Q5 | 15.3% / 38.5% / **41.0%** |
| 全国 农村 Q1 / Q3 / Q5 | 14.8% / 38.4% / 41.2% |
| C 档 城市 Q5 | 36.1% |

问题：
1. **家境到 Q2 以上就不起作用**：Q3→Q5 只差 2–3pp。北京城市最富家庭的孩子只有 64.6%，全国城市 Q5 只有 41%。
   这和需求「城市中产大概率上本科、抽到好签的人也要有，截图对比才有张力」正相反。
   根因：`bachelorWealth=0`、`stageWealth=0`、`generalWealth=0`。家境只在「高中能不能读完」这一个节点起作用。
2. **同家境下城乡完全一样**（`bachelorUrban=0`）。农村这个身份在家境之外没有任何独立作用，「农村孩子」这条叙事就塌了。

你在报告里说「汇总表无法唯一识别 β，所以置零」，这个判断是诚实的。但置零本身也是一个很强的假设，而且是错的那一边。
现在 `calibration_targets_v2` 给了分层目标，β 就可以识别了。

**要求**：在原有 17 项全部保持 PASS 的前提下，新增以下校准项，`npm run calibrate` 和 20000 局测试都要断言：

| 指标 | 目标 | 键 |
|---|---|---|
| 城市 Q5 出生队列本科率 | 60%–85% | urban_q5_bachelor |
| 农村 Q1 出生队列本科率 | 8%–18% | rural_q1_bachelor |
| 城乡各自 Q1<Q2<Q3<Q4<Q5 严格递增，且 Q5−Q3 ≥ 10pp | — | wealth_gradient |
| 同为 Q3：城市 − 农村 ≥ 5pp | — | hukou_gap_same_q |

注意：城市 Q5 拉上去以后，全国本科率会跟着涨。需要把 bachelorBase 或档位基准往下压，才能让「高考者本科录取 37–45%」「出生队列本科 28–40%」继续 PASS。这正是联合拟合的意义。
家境梯度主要应该作用在：普高录取（补课、择校）、高考本科（学校质量）、985（城市户口 + 高家境）。

## B. 引擎：成年去向分布不对（P0）

| 指标 | 01 实测 | 目标（cn-stats 键） |
|---|---|---|
| 出生队列硕士及以上 | 1.0% | 4%–9%（master_of_cohort） |
| 35 岁前进入体制内（公务员 + 事业编，含教师医生） | 0.07%（10 万人里 47 个） | 3%–7%（tizhi_by_35） |
| 40 岁时外卖骑手 + 网约车 | 16% | ≤ 5%（gig_at_40） |
| 40 岁时务农（农村出身者） | 0%（没有这个职业） | 5%–20%（farming_at_40_rural_origin） |

- 职业表要补：**务农、外出务工（建筑/工地）、个体户/小生意、教师、医护、事业编、老板**。现在 40 岁只有 6 种职业，其中两种是骑手和网约车，太单薄，也太像段子。
- 考公是「可以反复考」的：22–35 岁每年可选「备考公务员 / 事业编」，每次成功率由学历、档位决定，失败扣幸福 +1 年时间。二战、三战是中国特色的残酷感来源。
- 考研同理，允许二战。
- 35 岁节点：裁员概率要和行业挂钩（互联网 / 制造业 / 体制内差别很大），体制内基本不受影响。

## C. 文案：读起来是温吞的生活流水账，残酷感没有出来（P0）

Claude 读完了 `life-examples.json` 两局全部 400 多条日志。

1. **重复太严重**。「上楼时你歇了一会儿」在 69–75 岁出现 4 次；「运动会上你没拿名次」在 6、7、9 岁连续出现；
   「老屋的门槛还在」出现 6 次。一生读下来像同一页翻来覆去。
   → **同一模板一生最多 2 次，且两次至少间隔 5 年**；同年不重复（已有）。160 条不够撑一生不重复的话，扩到 **300 条以上**，主要补 23–60 岁。
2. **脚注是挂上去凑数的**。「午后邻居端来一碗鸡蛋羹」挂 `births.rural_share_of_births`；「新书包背上肩」挂 `compulsory_retention`。
   文本和统计毫无关系，等于为了凑 40% 的比例乱贴。
   → 规则改成：**`stat` 只能挂在内容真的在讲这个统计的事件上**，而且渲染出来的脚注**必须含具体数字**
   （「全国约 39% 的初中毕业生没有进普高（2024 教育统计公报）」）。比例要求取消。新要求是：
   **关键节点（中考、高考、22 岁去向、考公、考研、35 岁、离世）100% 带含数字的脚注**，日常事件宁缺毋滥。
3. **关键节点没有残酷感**。现在的裁决文案是：
   「你没有收到本科录取通知。成绩、家庭负担和名额共同影响了这次结果。」这是公文腔，没有残酷感。
   原作的力量来自**具体原因 + 具体的家**：「家里筹不出学费、制服和书本的钱，你只好放弃读高中。」
   → 每个关键裁决要按**实际起作用的因素**选原因文案（引擎要把主导因素传给文案层）：
   - 家境主导：「爸爸在东莞电子厂，一年寄回来两万出头。中职免学费，家里说先学门手艺。」
   - 成绩主导：「你差了 11 分。班里 48 个人，普高线上的有 26 个。」
   - 城乡 / 学校质量主导：「镇中学去年的普高升学率不到四成，你是那六成里的一个。」
   - 档位主导（高考）：「同样的分数，在北京能上一本。」——**这种句子只陈述事实，不评价制度**（见红线）。
   每类至少 4 条变体。
4. **没有家人**。整局日志里父母、爷爷奶奶几乎不存在，出生时抽的父母职业和留守状态没有进文案。
   → 玩家和父母都要有**中文名字**（姓 + 名，按性别和年代抽，词表放 `src/content/names.js`）。父母职业、留守、隔代抚养要驱动事件：
   留守儿童有「过年才见到爸妈」「爷爷用摩托车载你去镇上」；父母会生病、变老、离世（按年龄和寿命表），这些是中年线最重的部分。
5. **术语泄漏到玩家面前**（P0，这些不能出现在任何玩家可见文本里）：
   - 「家境 Q5」「家境 Q1」：要换成人话，如「爸妈都是大学老师，家里在海淀有房」「家里种着六亩地，爸爸常年在外打工」。
   - 「该路线概率为待核机制估计。」：内部备注，删。
   - 「终局类别：意外（意外）。」：重复，且像表格字段。写成「92 岁那年冬天，你在院子里摔了一跤，没再起来。」
     疾病写具体病名（脑卒中、肺癌、心梗……），按年龄段抽，**不写过程**。
   → `tests/banned-words.js` 增加一组「术语词」：`Q1 Q2 Q3 Q4 Q5 待核 估算 机制 类别 档位 pending stat`。
   **测试改为扫描 2000 局完整人生的实际日志 + 出生卡 + 终局页文本**，不只扫模板源码。
6. **出生卡太干**。「你出生在重庆，农村户口，家境 Q1。」应该像原作那样是一段人话：
   「2026 年 11 月，你出生在重庆市彭水县的一个村子。爸爸 31 岁，在广东的工地上；妈妈 27 岁，生完你三个月也要出去。
   你会跟着奶奶长大。」——县名可以用省内县名词表（`src/content/places.js`，每省 5–10 个，**只用于地名，不附任何评价**）。
