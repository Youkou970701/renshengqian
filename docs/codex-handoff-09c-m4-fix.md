## 1. 首页命中禁词（裁定）

  完整的状态标注只在「统计出处」页展示；`player-text` 测试可以对统计出处页单独豁免这三个词（写明原因），首页和游戏内仍然禁止。
- 「略过沉重情节」说明里的「家暴」改成「家庭暴力」（禁词表里的「家暴」是 V1 时期的，不改禁词表）。

## 3. 称号库重写（P0，测试抓不到）

现状 146 个，大半读起来不像人话，也没有传播力：
- 「的」字层层叠：「离开牌桌的那一步**的**人生」「南下夜班车上的人**的**人生」「货架前一步的后果**的**人生」「专科起步的路**的**人生」；
- 虚、散文腔，看不出这一生特别在哪：「把字写成工作的人生」「在流水线上谋生的人生」「月末账单的重量的人生」；
- 设计稿要的是「从流水线干到车间主任的人生」「三战上岸的人生」「拆迁暴富、十年花光的人生」——**具体、有数字、有起伏**，这是玩家会截图发小红书的那一句。

**称号公式**：`［这一生最突出的那条轨迹，用一个动作 + 具体结果说出来］的人生`。整个称号**只允许一个「的」**（结尾那个），尽量带上这一局的真实数字或地名。
从这一局的实际数据里挑最突出的一条（按稀有度排序，越稀有越优先），例如：

| 轨迹 | 称号样例（数字和地名用这一局的真实值） |
|---|---|
| 职级爬升 | 从普工干到车间主任的人生 · 从学徒干成老板的人生 · 在讲台上评上高级教师的人生 · 跑了二十年外卖的人生 |
| 考试 | 三战上岸的人生 · 复读一年考上 985 的人生 · 考了五次公务员没考上的人生 · 留守儿童考上 985 的人生 |
| 财富起落 | 拆迁暴富、十年花光的人生 · 赌掉一套房的人生 · 白手起家攒下千万的人生 · 开了三家店倒了三家的人生 |
| 地点 | 从贵州村子走到深圳的人生 · 一辈子没离开饶平县的人生 · 北漂十五年回了老家的人生 |
| 家庭 | 养大四个孩子的人生 · 离了两次婚的人生 · 七十三岁又结婚的人生 · 给父母治病卖了房的人生 |
| 越界 | 喝了一次酒丢了工作的人生 · 借出一张银行卡坐了一年牢的人生 · 跟着「大哥」混过三年的人生 |
| 躲开 | （躲开本身不够突出，只有没有其他更突出的轨迹时才用）那天没有上牌桌的人生 |
| 寿命 | 活到一百零二岁的人生 · 没能过完十八岁生日的人生（早逝要克制，不写死因） |

- 「越界」类在**分享卡**上换中性说法，但仍要具体、自然：「走过一段弯路的人生」「重新开始过一次的人生」。**离婚、生病、失业、父母离婚不是需要回避的词**，分享卡上可以直接写。
- 数量 ≥ 100 个模式（带变量的模板算一个），M4 原有的频率门槛照旧（覆盖 100%、最常见 <15%、<1% 的 ≥20 个）。
- 新增测试：称号文本里「的」只出现一次；不含禁词；至少 60% 的称号模板带有本局变量（数字、地名、职级、次数）。

## 4. 一句话传记（P0）

终局卡样例「出生在浙江，22 岁时做过工厂工人，做过保洁，12 岁时经历家庭住址的分开，有 2 个孩子，48 岁因脑卒中离开」：
- **按年龄顺序写**（现在是 22 岁写在 12 岁前面）；
- **不委婉过头**：「家庭住址的分开」→「12 岁那年父母离婚」；
- 「你读到初中未完成」→「初中没读完」；
- 像一个人在讲这个人的一生：「出生在浙江金华的一个村子，12 岁那年父母离婚，初中没读完就进了厂，后来做保洁，养大两个孩子，48 岁因脑卒中离开。」
- 新增测试：传记里出现的年龄严格递增；不出现「住址的分开」「未完成」这类生硬词（建一个「生硬表达」清单，Claude 验收时补）。
