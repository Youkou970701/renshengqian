## 0. 总原则

1. **校准骨架保留**：原 25 项校准全部仍须 PASS；分层梯度（城乡 × 家境 × 档位）是残酷感的保证，不能被新系统冲淡。
   引擎大改以后，随机数消耗必然变化，**允许重建快照**（新快照叫 `calibration-v2.json`），不再要求和 03 逐字一致。
2. **确定性不变**：同编号 + 同输入序列 = 同人生。新系统（卡池、剧本、花钱菜单）的所有随机都走 rng，输入序列要包含菜单操作。
3. **引擎仍是纯函数**；内容（卡、剧本、职业表、称号）全在 `src/content/`，引擎只认 schema。
4. 「再大胆一点」的尺度 + 硬红线见 design-v2 第 4.6 节，**写死在测试里**。

## M1：抉择卡引擎 + 教育树 + 节奏

### 卡 schema（`src/content/cards/*.js`）
```js
{ id, stage: 'child'|'teen'|'high'|'college'|'adult'|'midlife'|'senior',
  when: s => boolean,            // 触发条件
  weight: s => number,           // 抽中权重
  cooldown: 年数, maxPerLife: 默认 2,
  title, body: s => string,      // 人话，有具体细节
  options: [{ id, label, hint,   // hint 写清代价，例如「每年 1.8 万学费」
              cost?, effects: s => patch, requires?: s => boolean,
              seeds?: [{ cardId, inYears: [min,max], chance }] }],   // 伏笔
  heavy?: true, stat?: 'cn-stats 键' }
```
- 每年：先结算重心，再从卡池抽 **0–2 张**（无卡的年份是常态，有卡的年份不超过 2 张）。伏笔卡优先于随机卡。
- 删除固定年龄的 9 张卡，改成卡池里有 `when` 的卡（中考、高考这类节点仍然必到，但选项按处境变化）。
- **考研 / 考公改成「备考状态」**：选一次进入，之后每年自动考，菜单里可以放弃。**不再出现「今年还要再试一次吗」**。
- 今年的重心按阶段换选项（design-v2 第 3 节表格），重心累积到隐藏值：技能、人脉、感情、名声、健康习惯。

### 教育树（design-v2 第 4.2 节，全部要做）
15 岁没进公办普高时至少 6 条路：民办高中（按家境判断交不交得起）、复读初三、中职选专业、艺体特长、国际学校 / 出国、不读了（接 M3 江湖路）。
另外：高中中途退学；艺考体考单独骰子；**学科竞赛**（初中起，省一等奖以上走强基或保送）；**专项计划**（Q1–Q2 农村、成绩前 20%，多一次录取机会）；
志愿卡选专业（影响 M2 的行业）；**大学学费卡**（家里出 / 助学贷款 / 勤工俭学 / 退学）；大学每年重心（学习、兼职、恋爱、旅游、考证、实习）；
保研、考研、出国读研；成人第二次机会（成考、自考、开放大学、夜校、在职研究生）。
**富豪线**：Q5 里再抽前 1%，专属卡（私教、国际学校、常春藤、接班、联姻压力、挥霍、被骗）。
**穷孩子爽文线**：成绩前 20% 的 Q1–Q2，连续遇到贵人老师、免学费、竞赛、专项、助学金。整体比例由校准管住。

### M1 门槛
- 每局有效抉择（卡 + 重大节点，不含重心）中位数 **≥ 18**（M3 后要到 30）；同卡一生 ≤ 2 次；「再试一次」类卡出现 0 次。
- 15 岁没进公办普高的人里，**至少 4 种去向各占 ≥ 3%**。
- 原 25 项校准 PASS（普高率、本科率、985、分层梯度都还在区间）。
- 新增：助学贷款触发率（考上本科的 Q1 中 ≥ 40% 会看到学费卡）、竞赛和专项的录取人数打印出来（不设硬断言，Claude 判断）。

## M2：职业与钱

- **职业表** `src/content/jobs.js`：约 30 个职业，每个 3–6 级阶梯，每级收入区间，晋升条件（年资、重心、技能、运气），
  行业标签（接行业周期）。清单见 design-v2 第 4.3 节表格，可以扩，不要少于 25 个。
- **收入**改成：职业 × 职级 × 城市 × 个人分位（入职时抽，之后随表现漂移）× 行业年景。删掉 `incomeByEdu` 公式。
- **找工作和失业**：有时长；失业期间收入 0。
- **经营系统**：开店 / 小厂 / 网店 / 补习班，每年一个年景骰子（好、平、难熬、关门），可请人、扩张、借钱、转让。
- **花钱 / 行动菜单**（design-v2 第 4.4 节）：UI 里随时可开，引擎里是输入序列的一部分。
  首批必须有：补习班、兴趣班、择校、考证、体检、旅游、买车、买房（老家 / 县城 / 省会 / 一线 × 小房 / 正常）、房贷、
  提前还款、卖房、给父母钱、借钱给亲戚、彩礼 / 嫁妆、存款、基金、炒股、理财（可暴雷）、网贷、彩票。
- **买房修复**：自动策略要会买房（按收入和积蓄），校准住房拥有率（Claude 会补数据；先打印 40 岁城镇居民有房比例）。

### M2 门槛（`data/cn-stats.json` 的 `economy` 节）
- 成年人收入按人头的五等份边界，贴近 2024 年人均可支配收入五等份（9542 / 21608 / 33925 / 53359 / 98809），每档误差 ±25%。
- 农民工路线的月收入中位数在 4500–5600 元。
- 同学历同城市的人收入 P90 / P10 ≥ 3。
- **90% 的人一生里至少有一次收入涨 ≥ 30% 或跌 ≥ 30%**。
- 「一辈子年收入都在同一个 5k 区间」的人 < 5%（用户说「很多人都是 3.6 万」，这条就是验它）。
- 原 25 项仍 PASS。

## M3：剧本库 + 关系家庭

### 剧本 schema
剧本 = 2–4 张连环卡，`{ id, category, trigger(s), steps:[card...], outcomes, longTerm }`。
`longTerm` 写进状态，长期影响后面的卡：**案底**（影响考公、参军、子女政审）、**征信**（影响贷款买房）、伤残、债务、名声。

### 首批 ≥ 40 个剧本，8 类各 ≥ 4 个（design-v2 第 4.6 节表格）
意外 · 被侵害 · 越界（醉酒闹事、赌博、小偷小摸、酒驾）· 江湖路（跟大哥混、网吧电竞、当兵、南下、学手艺）·
诱惑与陷阱（网贷、理财暴雷、保健品、婚托、传销、电诈）· 好运（拆迁、彩票、贵人、遗产、风口）·
家庭风暴（父母离婚、出轨、婆媳、孩子叛逆、**家暴**）· 身体（大病、抑郁、职业病）。
加上「大胆」内容：**坐牢全流程**（看守所 → 判决 → 服刑 → 减刑 → 探视 → 出狱被拒 → 案底）、**毒品**（被引诱 → 戒毒 → 复吸或戒断）、
**赌博到高利贷**（卖房、离婚、被催收、跑路）。

### 关系家庭（design-v2 第 4.5 节）
恋爱（初恋、大学、异地、分手）· 相亲卡写清对方条件和彩礼 · 婚姻亲疏和危机 · 离婚分财产 · **多个孩子** ·
谁带孩子（自己 / 老人 / 送回老家留守）· 鸡娃投入 → 接入家族接力的孩子起点 · 父母变老、大病、养老、遗产 · 兄弟姐妹借钱和分家。

### 35 岁以后
design-v2 第 4.8 节的清单全部做成卡或剧本。

### M3 门槛
- 每局有效抉择中位数 **30–50**；**35 岁以后 ≥ 10 个**。
- 每局触发剧本：平均 2–4 个，0 个的局 < 10%，≥ 6 个的局 < 5%（不能每局都狗血）。
- 「越界 / 江湖」类剧本的结局：坏结局（坐牢、伤残、倾家荡产、众叛亲离）≥ 60%，洗白成功 ≤ 15%。
- **硬红线测试**（扫描 2000 局实际日志 + 全部卡文案）：不出现方法性描述（准备一个禁词表：作案手法、赌术、吸食方式、诈骗话术等，
  你先建，Claude 验收时补）；不出现性暴力；自杀只出现「离开」类表述并带热线；不出现上访、群体事件、强拆冲突、政策评价；
  「略过沉重情节」开关打开时，犯罪、毒品、赌博、家暴、自杀、重病类剧本触发次数为 0。
- 分享卡上不出现犯罪、毒品、家暴字样。
- 原 25 项仍 PASS。

## M4：结局、重玩、首页

- **一句话传记 + 称号**：从这一生最突出的事件生成，称号库 ≥ 80 个（`src/content/titles.js`），进人生图鉴收集。
  例：「从流水线干到车间主任的人生」「三战上岸的人生」「拆迁暴富、十年花光的人生」「赌掉一套房的人生」「在县城开了二十年五金店的人生」。
  分享卡上的称号换成中性说法（犯罪、毒品、家暴相关称号只在站内显示）。
- **人生底色**：四组对立轴（安稳—折腾、顾家—顾己、留下—离开、认命—不认命），按实际选择计算，出名字和一张分享卡。
  **不要用原作的四组词和十六种名字**，我们自己起。
- **重新抽签**（用户定，**不做自选出身**）：出生卡上一个醒目的「重新抽签」按钮，点一下立刻换新身份（新编号、新出生卡），
  不限次数、无门槛、1 秒内出结果。被放弃的身份记在本机，首页小字「你放弃过 N 个身份」。
  每日一签和家族接力的孩子不能重抽（按钮隐藏，写一句原因）。
- **首页重做**（design-v2 第 5 节第 6 条）：实时出生 / 离世计数、31 省出生占比图、按分布模拟的「刚刚有人出生在……」滚动条（标注「按统计模拟」）、
  你的前世（本机人生小卡片）、今日签 / 极速 / 图鉴入口、三段玩法说明、略过沉重情节开关。D 数据新闻风格，信息密度对齐原作。

### M4 门槛
称号覆盖率：10 万局里每局都能拿到称号；最常见的称号 < 15%；≥ 20 个称号 < 1%。人生底色四轴分布不能塌在一边（每轴两端各 ≥ 15%）。

## M5：内容扩量与整体校准

- 卡池总数 ≥ 200，剧本 ≥ 50，职业 ≥ 30，称号 ≥ 100。
- 全量校准 + 分层探针 + 全部门槛再跑一遍；`calibration-v2.json` 定稿。
- 节奏实测：30 分钟档一局实际 25–35 分钟（有卡的年份停下等玩家，计时只算推进时间）。
- 原有玩法回归：命运骰子、家族接力、每日签、图鉴、极速局、分享卡都要接上新系统（例：家族接力的孩子起点用新的收入 / 房产；极速局只播关键节点 + 剧本高潮）。

## 补充（2026-10-22 第二批用户反馈，并入对应里程碑）

详见 `docs/design-v2.md` 第 9 节。要点：
- **M2**：职业 ≥ **40** 个，必须包含自由职业、医生、军人、老师、服务员、保洁、保安、厨师、护工、快递员、房产中介、保险销售、网店店主、律师、会计。
- **M3 婚恋**：恋爱、分手、结婚、离婚、再婚可以多次发生，70 多岁也能再婚；**每个对象有资料卡**（年龄、籍贯、学历、职业、年收入、存款、房车、性格、家庭、彩礼要求），选择前可见；
  婚姻危机卡选项：忍 / 冷战 / 咨询 / 分居 / 协议离婚 / 起诉离婚。
- **M3 离婚按《民法典》**：婚前财产归个人、婚后共同财产才分；协议离婚 30 天冷静期可反悔；一方不同意只能起诉，第一次起诉通常不判离、分居满一年再诉判离；
  玩家可以拖着不离。加测试：和高资产对象婚后 1 年内离婚，分到的钱不得超过婚后共同财产的一半。
- **M3 彩礼分地区**：金额按省份 × 城乡（Claude 补到 `data/cn-stats.json`，没补之前用参数并在 results 的数据请求里列出）。
- **M3 好坏平衡**：每局「好结局」和「坏结局」剧本各至少 1 个的局 ≥ 60%。
