# 人生签 v3：为什么没有原作好玩 + 手机卡顿（Claude，2026-10-27）

> 用户转述朋友反馈：「这个游戏很卡，手机上」「真的没有之前给你那个网站好玩」「可以逆向开发吗」。
>
> **关于逆向**：原作 v0.7.31 起条款写明「未经许可，不得原样复制 80亿分之1 的程序码、文字与图像，或修改后散布」，「用这些点子创作属于自己的新作品，是自由的」。
> 逆向它的代码再改写属于明确禁止的范围，我们是公开仓库、要发小红书，风险很实际。**结论：不扒代码和文案，只学机制**——下面的差距全部是「点子」层面，实现和文字都自己写。
>
> 原作此时已是 v0.8.60（10/22 是 v0.8.3，5 天发了 57 个版本）。

## 一、卡顿（P0，可以直接修）

Claude 实测：
- **引擎不慢**：推进一年中位 0.06 ms，整局 111 步共 20 ms。
- **每次界面状态变化都整份存档**：`src/ui/App.jsx` 第 167 行 `useEffect(()=>localStorage.setItem(SAVE_KEY, JSON.stringify(state)), [state])`。
  - 状态里除了自己的人生，还有**同秒出生 4 个人的完整人生**（2 岁时 peers 10KB，自己 3KB；到 80 岁自己约 77KB，加 peers 约 400KB）；
  - 状态里还有 `pacingElapsedMs`，计时每走一下就变，每变一次就整份 stringify + 同步写 localStorage。电脑感觉不到，手机上就是一顿一顿。
- **主包 853KB（gzip 320KB）**：十万局参照表、图鉴频率、全部内容一次性打进首屏。

修法：
1. 存档**节流**：只在「推进一年 / 做完选择 / 页面隐藏 / 关闭前」存；计时、动画帧不触发存档。
2. **同秒出生的 4 个人只存编号和他们已经推进到的年龄**，读档时用确定性模拟重算（引擎是纯函数，同编号同输入一定得到同样的人生）。
3. 人生纪录列表**只渲染最近 30 条**，其余点「查看更早」再展开；纪录项用稳定 key + memo，避免每年重渲染几百条。
4. **按需加载**：参照表（reference.json）、图鉴频率、称号库、统计出处页用动态 import，首屏只加载出生和游戏主循环需要的。
5. 验收：375px 中端手机（Chrome 4× CPU 降速）推进 60 年，主线程长任务（>50ms）≤ 3 次；首屏 JS gzip ≤ 150KB；存档写入每年 ≤ 2 次。

## 二、为什么没有原作好玩（同样 50 岁左右，两边主界面实测对比）

| 原作（巴基斯坦，54 岁） | 我们（粤-2026-694669，50 岁） | 差距 |
|---|---|---|
| 「Abdullah 拿着学校颁的奖状跑了进来」「母亲的忌日，家人聚在一起」 | 「公司通知换系统，你和同事对着新页面把操作步骤记下来」 | **家人是活的 vs 家人是背景**。我们界面上看不到配偶和孩子叫什么、几岁、关系好不好 |
| 「隔壁的孩子」：深夜的哭声 → 去敲门 / 和孩子说说话 / 装作不知道；下一条：「那家父母叫你别多管闲事。不过，你从此开始留意那个孩子」 | 卡片几乎全是自己的升学、工作、买房、带孩子 | **没有和别人有关的两难，选了也没有后续** |
| 「大雨让社区淹水，你好几天没法上班（−585 元）」 | 「所在行业进入新的年景周期，岗位薪酬系数由 0.99 调整为 0.96」「求职空档已经结束，今年按完整十二个月发薪」 | **机制的话漏给玩家**；钱的变化没有故事 |
| 「过去一年净资产 +2761：省吃俭用还的债 +1904、利息 −1110、住自己房子省的房租 +924、房价变动 +833」「巴基斯坦前 29% · 全世界后 31%」 | 「可用现金 38,898 元」 | **钱看不见来龙去脉**，也不知道自己在人群里的位置 |
| 「兴趣：画画 Lv.26」「天分：绘画」 | 无 | **没有成长进度** |
| 一幅随人生变化的小画（房子、家里几口人、职业道具） | 无 | **没有画面** |
| 每年重心写明代价：「埋首工作：收入·升迁↑ 健康·人际关系↓」 | 下拉框只有名字 | 选择的代价看不见 |
| — | 「社区小店这一年收支平常，扣除经营开支后结余 35750 元」连续 3 年一字不差 | **重复** |
| — | 50 岁失业、收入 0，幸福 100 | **数值失真** |

## 三、v3 方案（按「好玩」的收益排序，全部自己实现）

### 1. 家人和朋友是活的（P0）
- 界面加「家人与生活」：配偶、每个孩子、父母、兄弟姐妹、好朋友——名字、年龄、职业、**关系亲疏**（会因选择和事件变化）。
- 日常事件优先写「人」：孩子的奖状、配偶的生日、父母的忌日、朋友的婚礼……用名字。
- 关系亲疏影响后面的卡（疏远的孩子不来看你、亲近的兄弟肯借钱）。

### 2. 和别人有关的两难 + 后续（P0）
- 新卡类「身边的人」：邻居、同事、陌生人、亲戚、老同学——隔壁的孩子、同事被冤枉、路上有人倒地、亲戚借钱不还、朋友找你做担保、举报单位违规……
- 每张都有**后续**（伏笔机制已有）：一两年后回来一条「你从此开始留意那个孩子」「那个同事后来升了领导，还记得你」。

### 3. 去掉机制腔，钱有故事（P0）
- 禁止玩家文本出现「系数」「按完整十二个月」「恢复了在岗工作」「收支平常」这类账房话（加进生硬表达清单）。
- 年度经营结果、行业周期改写成**具体事情**：「今年街口又开了一家同样的店，生意被分走一半」「厂里接了个大单，连着加了三个月班，年底多发了一个月工资」，每种结果至少 6 种说法，不连续重复。
- 钱面板：「过去一年净资产变化」按来源分解；「收入在全省第 X%、全国第 Y%」。

### 4. 成长进度（P1）
- 兴趣和手艺有等级（Lv），每年重心选「兴趣 / 学技能」会涨；到一定等级解锁卡（接私活、开班、比赛、出书……）。
- 天分（已有）在面板上显示出来。

### 5. 每年重心写明代价（P1）
- 下拉框改成按钮组，每个写清楚「↑什么、↓什么」。

### 6. 一幅会变的画（P1，视觉投入最大）
- 风格要和原作的横版像素画拉开（我们是数据新闻风）：建议**扁平剪纸 / 线描**，按状态拼出：住处（村里平房 / 城中村 / 小区 / 别墅）、家里几口人、职业道具、季节和年龄。
- 先做 6 种住处 × 3 种家庭规模 × 12 种职业道具的组合。

### 7. 数值修正（P1）
- 幸福受收入、健康、关系、失业的影响，不能失业还 100。

## 四、建议顺序

1. **先修卡顿**（一、半天量级，用户朋友已经在抱怨）；
2. 然后 v3 的 1 + 2 + 3（让人生「有人」、有两难、没有账房腔）；
3. 再做 4 + 5 + 7；
4. 最后做 6（画面）。
