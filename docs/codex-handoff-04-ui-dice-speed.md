## 2. 分享卡（这是小红书的弹药）

前端生成 PNG，1080×1920，零上传：
1. **出生卡**（B 车票）：始发站 = 出生地，车次 = 出生编号，家庭条件、父母、照护，一句「这一生，准备出发」。
2. **终局卡**（D 点阵）：大数字「X / 100 人」+ 100 方块点阵（你是高亮那一格）+ 一句话 + 编号。
- 两张都在底部印编号和「投胎模拟器」字样（**不印网址**。小红书对站外链接敏感，网址放主页简介就行）。
- 一键「保存图片」。手机上要能直接长按存图或调起分享，iOS Safari 要实测下载行为，不行就弹出图片让用户长按。
- 导出用 SVG → canvas → PNG，或者沿用 03 的 `card.mjs` 思路。**不引 html2canvas 这类会被系统字体坑的库**，除非你验证过 iOS 上效果一致。

## 3. 命运骰子 + 差一点（上头玩法 ①）

关键裁决（中考普高、高考本科 / 211 / 985、复读、考研、考公、35 岁岗位）在揭晓前：

1. 先亮出**你这一次的概率**：「普通高中录取概率 **34%**」。
2. 再给一行**影响因素拆解**，把 logit 贡献换算成百分点，按绝对值取前 3 项：
   「家境 −12% · 成绩 +8% · 省份 −5%」。这一行就是残酷感的来源：玩家第一次看见「我努力了，但家境扣掉的比我挣到的多」。
   换算方法：把该项贡献置零重算概率，前后的差就是这一项的百分点。和 02 的主因归因用同一套数，不另造。
3. 揭晓动画：一根 0–100% 的条，指针滚动后停在本次抽样值 u 上，**u < p 为通过**。动画 1.5 秒以内，极速局 0.4 秒。
4. **差一点**：没通过且 u − p < 5 个百分点时，显示「**只差 X%**」，并在终局页「这一生最接近的一次」里留一行。
   通过且 p − u < 5 时显示「**险过**」。

**引擎约束**：u 和 p 本来就在算（02 的归因记录了 logit 贡献、抽样值和概率），这次只是把它们放进事件 payload 给 UI 用。
**不允许改变随机数消耗顺序**。改完 `npm run calibrate` 的 25 项数值要和 03 **逐字一致**，再加一条测试断言这一点
（把 03 的 `calibration-result.json` 存一份快照做比对）。

## 4. 一分钟极速局（上头玩法 ⑤）

- 首页入口「极速一局」：全程自动重心和自动抉择，**只播关键节点**（出生、中考、高考、22 岁去向、结婚生育、35 岁、父母离世、自己离世），
  日常事件不显示，但引擎照常跑（机制和普通局完全相同，只是 UI 过滤）。
- 目标时长 60 秒 ±15 秒，命运骰子用 0.4 秒短动画。
- 结束直接进终局页，「再投一次」按钮要大，点下去 1 秒内出新的出生卡。**再来一局的摩擦越小越上头。**
- 极速局也能存终局卡。

## 5. 测试

- 原 28 项 + 校准快照逐字一致。
- 骰子：对 2000 局抽样，UI payload 里的 (p, u, pass) 满足 `pass === (u < p)`；拆解前 3 项按绝对值降序；百分点之和与总概率偏离在合理范围（只断言符号和排序，不断言可加性）。
- 「只差」只出现在 fail 且 p ≤ u < p + 0.05；「险过」只出现在 pass 且 p − 0.05 < u < p。
- 极速局：模拟时钟跑 200 局，时长分布的中位数在 45–75 秒。
- 分享卡：Node 端渲染两张样卡做像素尺寸断言（1080×1920）；术语扫描覆盖卡片文字。
