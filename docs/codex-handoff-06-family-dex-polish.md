## 1. 家族接力：二代、三代 100% 城市户口（P0）

你的 05 报告自己写了：「二代出生 2085 人，三代出生 882 人；**两组均为城市户口**」，原因是自动策略 25 岁一律选县城或省会。
你没有改自动策略，以免破坏第一代校准，这个判断是对的。但结果是：**「走出村子」这个目标第一代死后自动达成**，
「上一世是留守儿童，这一世让孩子留守」这条最有情绪的回环也永远不会发生。

**修法：不碰第一代的 RNG 和自动策略，只改「孩子出生在哪、什么户口」的派生规则。**
现实是：在城市打工 ≠ 孩子在城市出生长大。没有房、户口在农村、收入低的父母，孩子大多出生在老家、户口在农村，而且常常留守。
派生时按父代终局的这几项决定孩子的出生地和城乡：

| 父代情况 | 孩子 |
|---|---|
| 农村户口出身 + 未买房 + 收入后 50% | 大概率出生在父代老家（农村户口），并按较高概率留守（父母继续在外打工） |
| 农村户口出身 + 在定居城市买了房，或本科及以上 | 大概率出生在定居城市（城市户口） |
| 城市出身 | 维持现有规则 |

具体概率由你定，放进 params.js，但要满足下面的新断言（`status=参数`，这是产品目标，不是统计）：
- 农村出身、非本科、未买房的父代 → 孩子农村户口比例 **≥ 50%**；其中留守比例 **≥ 30%**。
- 农村出身、本科且买房的父代 → 孩子城市户口比例 **≥ 70%**。
- 1000 个农村 Q1 起步的家族（自动策略）里，三代内达成「走出村子」（有一代以城市户口出生）的比例在 **30%–80%** 之间：
  不能是必然，也不能是不可能。
- 留守的孩子要触发 02 已有的留守事件线；父代自己当年也是留守的，加 3 条以上专属回环事件
  （例：「你小时候等爸妈过年回来。现在，是你的孩子在电话那头问你什么时候回去。」）。

**姓氏**：孩子随父姓。玩家是女性时，孩子姓配偶的姓。现在样例里女性玩家孙可欣的孩子姓孙，不符合大多数家庭的实际情况。
家族卡标题用第一代的姓（「孙家三代」）也行，但不要靠孩子随母姓来维持姓氏连续。

二代、三代的城乡 / 家境 / 留守分布表重新写进 results。

## 2. 成就：名字看不懂，一大半太常见（P0）

05 的 30 个成就里：
- **太常见**：「两个人的餐桌」76937、「读到毕业那年」74399、「另一座城市」69268、「那张高中通知」58716，10 万局里出现五六万次以上，这不叫成就。
- **名字看不懂**：「远方的录取信」「另一座桥」「再试一次的回音」「多了一只小碗」，玩家看了不知道自己做成了什么。
  你回避「全村第一个」是对的（引擎没有全村数据），但回避过头了，所有名字都变成了散文标题。

**改法**：
- 名字**直白说出发生了什么**，≤ 8 个字，下面一行写条件。小红书截图里别人一眼要看懂：
  「家里第一个大学生」（父母都没有本科，你读到了本科；引擎有父母学历，可以判定）、「留守儿童考上 985」、「复读一年考上本科」、
  「考公第三次上岸」、「只差 1% 没考上」、「农村户口读到研究生」、「北京长大读了专科」、「活过 100 岁」、「一辈子没离开县城」。
- 频率分层：**入门 ≤ 5 个**（频率可以 > 30%，给新手第一局就有收获）；其余 25 个都要 < 10%，其中至少 8 个 < 1%（稀有，是截图点）。
- 依然不碰死因、疾病；不嘲讽；不给省份贴标签。新名字进禁词扫描。
- 「10 万次模拟里出现 X 次」的口径保留。

## 3. 骰子因素标签统一（P1）

探针统计到的因素标签：成绩、**求学条件**、省份、**报考地区**、所在行业、家境、备考投入、学历。
- 「求学条件」是什么？如果是城乡户口，就叫「**城乡**」；「报考地区」和「省份」是同一件事，统一成「**省份**」。
- 最终只用这几个：**家境、城乡、省份、成绩、努力、学历、行业**。玩家要能一眼把「家境 −12%」和自己的出生卡对上，委婉词会削弱这一下的冲击。
