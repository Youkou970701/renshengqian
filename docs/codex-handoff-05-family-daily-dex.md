## 1. 家族接力三代（上头玩法 ②，主题最强的一条）

一句话：**你死后，接着做你的孩子；孩子的出身就是你的终局。**挑战「三代人能不能从村里走出去」。

### 1.1 机制
- 终局页：如果这一生有孩子，出现主按钮「**接着做你的孩子**」；没有孩子就写「这个家的故事停在了第 N 代」（残酷，但照实写）。
- 孩子的出生**由父母终局确定性派生**：
  - 省份 = 父母最后定居城市所在省（去了一线就跟着一线所在省；回老家就是老家）。
  - 户口 = 父母定居地的城乡。
  - 家境五分位 = 父母（玩家 + 配偶）的收入 / 资产在全国的分位，加噪声。**要有向下流动的可能**，不是只升不降。
  - 父母 = 玩家和配偶（名字、年龄、职业都沿用）；姓氏继承。
  - 种子 = hash(父代种子, 代数)；编号加代数后缀：`粤-2026-694669·二代`。年份 = 父代出生年 + 生育年龄（只是标签，统计仍用「现在的中国」）。
  - 有多个孩子时，玩长子 / 长女（第一个出生的）。
- **祖辈出现在孩子的人生里**：二代的童年事件里，玩家上一世的角色就是爷爷奶奶（外公外婆）。上一世是留守儿童、这一世给孙辈带娃，
  这种回环是这个玩法的情绪核心。至少 10 条「祖辈 = 上一代玩家」的专属事件模板。
- 最多 3 代；第 3 代结束出「家族终局」。

### 1.2 家族目标（开局可选一个，也可以不选）
- 走出村子：三代内有一代在城市定居。
- 第一个大学生：三代内有人读到本科。
- 三代本科：每一代都本科。
- 回到原点：自由玩（不设目标）。

### 1.3 校准 / 合理性（新增断言）
- 代际相关：父代本科且在城市定居的孩子，家境 Q4+ 的比例 **>** 父代初中且务农的孩子。
- 不是确定性的：父代 Q5 的孩子里至少 10% 落到 Q3 及以下；父代 Q1 的孩子里至少 10% 升到 Q3 及以上。
- 第一代校准 25 项不受影响（家族模式不改第一代的抽签）。
- 二代、三代出生分布打印出来写进 results（不设硬断言，Claude 判断）。

### 1.4 家族卡（分享卡第 3 种）
1080×1920，三行，每代一行：名字、出生地、学历、定居地、寿命，代与代之间画箭头（上升 / 持平 / 下降）。
顶部一句话：「三代人，从饶平县的村子走到了广州」或者「三代人，都没离开饶平县」。

## 2. 每日一签（上头玩法 ③）

- 首页入口「今日签」：编号由**北京时间日期**派生：seed = hash('daily-' + YYYY-MM-DD)。全国玩家同一天拿到同一个出生。
  日期计算放在 UI 层（引擎仍禁 `Date`），按 Asia/Shanghai 取日期，跨零点要测。
- 出生卡上标「10月22日 · 今日签」。选择会让结果不同，评论区可以比谁把同一个开局玩得更好。
- 本机记录今日首局结果；同一天可以重玩，但终局卡只在**首局**印「今日签 · 首局」，重玩印「今日签 · 第 N 局」（防止刷到好结果再晒）。
- 首页显示今日签的一句话预告（只预告出生地和城乡，不剧透结果）：「今天，你会出生在贵州的一个村子。」

## 3. 人生图鉴（上头玩法 ④）

本机收集册（localStorage，加导出 / 导入 JSON 以防换机丢失）。

### 3.1 收集项
- **31 省**：出生过的省份点亮，地图或网格都行。地图如果用 SVG，**必须是完整的中国地图**（含台湾、南海诸岛），
  拿不到合规底图就用网格，不要冒险。
- **出身格**：城乡 × 家境 5 档，共 10 格。
- **终局**：学历 9 档、职业 15 种、寿命段（<30、30–59、60–79、80–99、100+）。

### 3.2 成就（约 30 个）
- 稀有度用**模拟频率**，不是真实统计：脚本跑 10 万局生成 `src/content/achievements-rarity.json`，界面写「**10 万次模拟里出现 X 次**」，
  不要写成「全国每 1 万人有 X 人」（那就是把模拟冒充统计了）。
- 示例（你可以扩充）：全村第一个大学生（农村 Q1 读到本科）、留守儿童考上 985、复读上岸、三战考公上岸、
  只差 1%（命运骰子差一点 < 1%）、北京城市家庭但读了专科、活过 100 岁、一生没离开出生的县、35 岁被裁后重新上岸、
  家族三代本科、二代进城、每日一签连续 7 天。
- **红线**：成就不碰死因、自杀、疾病；不用嘲讽性命名（不要「废物」「躺平王」这类词）；不给省份或城乡贴标签。
  成就名加进术语 / 禁词扫描。
- 解锁时弹一个小提示，终局页列出本局新解锁的成就。

## 4. 测试

- 家族：派生确定性（同父代终局 → 同孩子出生）；无孩子时没有接力按钮；第 3 代后结束；1.3 节的断言。
- 每日：固定日期 → 固定编号；Asia/Shanghai 跨零点（用 UTC 15:59 和 16:01 两个时刻测）；首局标记。
- 图鉴：导出→清空→导入 往返一致；稀有度文件由脚本生成且和引擎版本一致（存引擎哈希，不一致就报错，提醒重跑）。
- 禁词 / 术语扫描覆盖成就名、家族卡、每日签预告。
- 25 项校准仍与 03 快照逐字一致。
