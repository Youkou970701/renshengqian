# 人生签 v2 设计方案：从「看一个人被统计推着走」到「人生百态」

> 日期：2026-10-22 · 作者：Claude · 状态：**用户已确认（2026-10-22）**：分期合并一起做；剧本尺度「再大胆一点」；默认一局约 30 分钟
> 起因：V1 上线后，用户和朋友试玩反馈：
> 1. 选择太少，后面年年问「考研 / 考公」，太单调；
> 2. 很多人一辈子年收入都是 3.6 万；
> 3. 考不上高中只能辍学。没有私立高中、复读、学手艺、混社会这些路；有钱人家也不能出国；
> 4. 一年过得太快；玩一把就没兴趣；
> 5. 要「人生百态」：车祸、被抢、小偷、醉酒闹事、赌博……；
> 6. 考上大学没钱读的话，有助学贷款和补助；大学里有旅游、学习、兼职；艺术生、体育生从小培养；
> 7. （bug）手机上没点选择，往下滑，它自己就选了。
>
> 本文先诊断（用数据），再拆原作，最后给 v2 的完整设计和分期。

---

## 0. 诊断：为什么单调（3000 局实测）

| 现象 | 数据 | 根因 |
|---|---|---|
| 年年问考研考公 | 3000 局里「今年还要再试一次吗？」弹了 **24416 次**，人均 8 次 | 22–35 岁只有这一张卡在循环 |
| 35 岁以后没事可做 | 35 岁以后的抉择：**0 次** | 重大抉择写死在 9 个固定年龄（15/18/19/21/22/25/29/31/33/35） |
| 收入 3.6 万一辈子 | 峰值收入扎堆在 3 万、4 万、5 万、7 万、10 万、14.5 万几个桶 | 收入 = 学历底薪 × 城市系数 × 年龄段 × (1±12.5%)。没有职级、跳槽、绩效、生意、副业 |
| 没考上高中就辍学 | 15 岁卡只有 普高 / 中职 / 打工 | 教育是一条主干道，没有支路 |
| 一年太快 | 10 分钟走完 80 年 ≈ 7 秒一年 | 没有事的年和有事的年同速 |
| 手机自己选 | `automatic` 默认 **true**；抉择卡在手机上排在属性面板下面，用户往下滑时 5 秒倒计时跑完 | 默认值错误 + 抉择不是模态 |
| 引擎体量 | 整个引擎 **885 行** | 只够做「统计推进器」，做不了「人生」 |

**结论**：V1 的统计校准做得很扎实，但它是一个「推进器」，不是「人生」。v2 不是修补，而是要在校准骨架上加**系统**。

## 1. 原作为什么耐玩（读完它 v0.7.2 → v0.8.3 全部更新日志）

原作的统计只是地基，真正的深度来自这些系统（按重要性排序）：

1. **花钱 · 投资菜单**（6 岁起随时可打开）：补习班、兴趣班、课程、体检、旅行（国内 / 国外、和谁去）、外食、礼物、给家里寄钱、
   奖学金、买车、买房（小房子 / 一般房子，真实还款计划）、出租房、指数基金、提前还贷、遗嘱。**钱有地方花，选择就有了重量。**
2. **工作卡片 + 职级阶梯**：「这行第 N 年」「工作 40 年，一路升到技术副总」；找工作的时长按失业率；梦想职业可以挑战，落败会告诉你卡在哪里。
3. **开店 / 经营**：社区小店、小餐馆、修理店、补习班、诊所……要请人、打广告，有难熬的一年和顺利的一年；可以卖店，也可以交给子女。
4. **教育支路**：高中可以自己选退学、同等学力、夜校、边工作边读研、出国念大学、职校分科、艺术和体育高中、辍学后家境好转再回学校。
5. **天分 → 兴趣 → 专业 → 职业**一条线：小时候显露的天分会出现在兴趣卡、专业卡上；兴趣做出来的东西还能卖钱。
6. **关系**：交往、同居、结婚（卡上先告诉你对方的存款和负债）、夫妻亲疏、婚姻危机、离婚、谁带孩子、孩子要钱、兄弟姐妹借钱、请兄弟姐妹照顾父母。
7. **百态**：职场霸凌、传销、算命、给老师塞红包、车祸医药费、入狱、出狱后重新开始、战争动员、移民与遣返。
8. **结束以后**：一句话传记 +「××的人生」称号、「人生的纹理」（4 组对立词、16 种）、前世展示架、追思馆、分享人生的广场、
   每日主题、重新出生会留下一颗「石子」（放弃的人生不会凭空消失）。

它的条款允许「用这些点子创作属于自己的新作品」，但**不得复制代码、文字和图像**。我们只学系统，内容全部按中国现实重写。

## 2. v2 的设计目标（每一条都可以测）

| 目标 | 指标 |
|---|---|
| 选择多、而且不重复 | 每局有效抉择 **30–50 个**；同一张卡一生最多出现 2 次；**35 岁以后至少 10 个** |
| 路口多 | 15 岁没进公办普高的人，至少有 **5 条**可走的路；18 岁以后每个人至少遇到 3 条非主流路线的邀约 |
| 收入像真的 | 收入分布对上统计局五等份；同学历同城市的人收入差距 ≥ 3 倍；**90% 的人一生收入有起伏**（升职、失业、生意好坏） |
| 人生百态 | 每局至少触发 **2 个剧本**（第 5 节）；剧本库 ≥ 40 个 |
| 节奏 | 默认一局约 **30 分钟**（用户定）；有卡的年份停下来等你；没事的年份 3–5 秒过去 |
| 想再来一局 | 每局结束给出「××的人生」称号；称号库 ≥ 80 个，可收集 |
| 残酷感保留 | 原有分层校准（家境、城乡、省份梯度）全部保留 |

## 3. 核心循环：一年里发生什么

```
每一年 = ① 今年的重心（按人生阶段换选项）
       + ② 0–2 张情境抉择卡（从卡池里按状态抽，不按固定年龄）
       + ③ 随时可开的「花钱 / 行动」菜单（可选）
       + ④ 生活事件 1–3 条（有统计脚注的照旧）
       + ⑤ 剧本推进（如果身上有进行中的剧本）
```

**节奏**：默认一局约 30 分钟；没有卡的年份自动快进（约 3–5 秒）；出现卡就停下来等你选，**默认不自动选**。
「自动抉择」改成一个明确的模式（开局选「我只想看」才开），倒计时 ≥ 10 秒，手指碰到卡片就停止倒计时。
手机上抉择卡是**底部弹出的模态层**，不会被滑走。

### ① 今年的重心：按阶段换选项

| 阶段 | 选项（每年选 1 个，有明确的取舍） |
|---|---|
| 小学 6–11 | 学习 / 玩 / 兴趣班（家里出钱）/ 帮家里干活（农村、低收入） |
| 初中 12–15 | 学习 / 玩 / 兴趣特长 / 早恋 / 打游戏 |
| 高中 16–18 | 冲刺 / 艺考体考集训 / 谈恋爱 / 混日子 |
| 大学 19–22 | 学习（保研、奖学金）/ 兼职 / 社团和恋爱 / 旅游 / 考证 / 实习 |
| 打工、上班 23–60 | 拼事业 / 顾家 / 副业 / 学技能 / 躺平养身体 / 社交人脉 |
| 退休 60+ | 带孙子 / 旅游 / 养生 / 广场舞和老年大学 / 继续挣钱 |

每个重心都会累积到不同的隐藏值（技能、人脉、健康、感情、名声），这些值决定后面会出现什么卡、卡的成功率。

## 4. 系统设计

### 4.1 抉择卡引擎（替换固定年龄的 9 张卡）

- 每张卡：`{ id, 触发条件(state), 权重(state), 冷却, 选项[{文案, 代价, 即时效果, 伏笔}] }`。
- **伏笔**：选项可以埋下延迟后果，几年后触发另一张卡（借给发小 5 万 → 3 年后「他再也不接电话」或「他开着车回来还钱」）。
- 卡池目标：**V2 首批 150 张**，覆盖每个阶段；每年最多 2 张，同卡一生 ≤ 2 次。
- 考研考公改成一张「**进入备考状态**」的卡：选了以后，每年自动考，直到你在菜单里放弃或者考上。不再年年问。

### 4.2 教育：一棵树，不是一条路

```
小学 ──兴趣班（家里出钱）── 美术 / 音乐 / 舞蹈 / 体育 / 编程 / 奥数
  │        （天分高 + 坚持 → 特长生线）
初中 ──中考──┬─ 公办普高（分数线）
             ├─ 民办高中（交钱；家境决定能不能读）          ← 朋友反馈
             ├─ 复读初三（再考一次）
             ├─ 中职 / 技校（选专业：汽修、护理、电商、烹饪……）
             ├─ 艺体特长生（有天分 + 小时候练过）
             ├─ 国际学校 → 出国读高中 / 本科（家境前 20% 城市）  ← 朋友反馈
             └─ 不读了 → 第 4.3 节「江湖路」
高中 ──可以中途退学（成绩差、家里难、被霸凌）
     ──艺考 / 体考（单独一次骰子）
     ──高考 → 志愿卡：选城市 × 选专业（专业影响以后的行业和收入）
     ──复读（可再考一次）
大学 ──学费卡：家里出 / **助学贷款** / 勤工俭学 / 退学打工   ← 朋友反馈
     ──每年重心：学习 / 兼职 / 恋爱 / 旅游 / 考证 / 实习
     ──保研、考研、出国读研、毕业就业、考公
     ──**竞赛**：初中起可以走学科竞赛（数学、物理、信息学……），省一等奖以上有强基计划、保送机会   ← 朋友反馈
     ──**专项计划**：家境 Q1–Q2、农村、成绩前 20% 的学生，高考多一次专项录取机会（国家 / 高校 / 地方专项）   ← 朋友反馈
成年 ──第二次机会：成人高考、自考、开放大学、夜校、在职研究生
        （学历提升晚了，但会改变收入和职级上限）
```

助学贷款要有真实感：毕业后每年还款，拖欠影响征信；有国家助学金和奖学金卡（家境 Q1 + 成绩好的触发）。

**穷孩子的「爽文线」**（朋友：家庭虽然贫困但成绩很好，有各项补助）：整体比例照统计不变，但成绩好的穷孩子会连续遇到
贵人老师、县中免学费、竞赛、专项计划、助学金、奖学金、保研这些卡。玩家自己能感到「我在逆天改命」，同时脚注仍写清真实比例有多低。

**富豪线**（朋友：富豪家庭的培养）：家境前 1%（Q5 内再抽）的孩子，有私教、马术和钢琴、国际学校、常春藤申请、
家族企业接班或拒绝接班、信托、联姻压力等专属卡。富家孩子也有自己的坑：挥霍、被骗、接班失败、家族内斗。

### 4.3 职业与收入：职级阶梯 + 年资 + 行业 + 运气

替换 `学历底薪 × 城市`。每个职业有：

- **入口**：学历、技能、城市、人脉要求；
- **职级阶梯**（3–6 级），每级有收入区间；
- **晋升卡**：按年资、重心（拼事业）、能力、运气触发，可以失败；
- **行业周期**：互联网裁员潮、制造业外迁、房地产下行、外贸起伏（随机年份，影响一批人）；
- **失业与找工作**：找工作花几个月到一年以上，期间收入为 0；
- 收入在阶梯区间内按分布抽，不是固定值。

首批职业（约 30 个，每个配阶梯示例）：

| 线 | 阶梯示例 |
|---|---|
| 工厂 | 普工 → 熟练工 → 拉长 → 车间主任 → 厂长 |
| 工地 / 装修 | 小工 → 大工（瓦工、电工）→ 带班 → 包工头 |
| 学徒手艺 | 学徒 → 师傅 → 自己开店（理发、厨师、汽修、美甲、修手机） |
| 外卖 / 快递 / 网约车 | 骑手 → 站长；司机 → 买车自己跑（收入高但伤身体） |
| 销售 | 业务员 → 主管 → 区域经理（提成，波动大） |
| 白领 / 互联网 | 专员 → 主管 → 经理 → 总监（35 岁裁员风险高） |
| 程序员 | 初级 → 高级 → 架构师 / 技术经理 |
| 公务员 | 科员 → 副科 → 正科 → 副处（稳定，收入不高，福利好） |
| 教师 / 医护 | 职称：初级 → 中级 → 高级（医生要规培，前几年收入低） |
| 金融 | 柜员 → 客户经理 → 投行 / 基金（985 门槛，高收入高压力） |
| 当兵 | 义务兵 → 士官 / 考军校 → 转业 / 退伍安置 |
| 主播 / 网红 | 小主播 → （极低概率）爆红；大多数收入很低 |
| 务农 | 种地 → 承包 / 养殖 → 合作社（受天气和价格影响） |
| 开店 / 创业 | 见下面「经营」 |

**经营**（开店 / 小厂 / 补习班 / 网店）：每年一个「生意年景」骰子，有好年、平年、难熬的年、关门；
可以请人、扩张、借钱撑、转让。开店是农村和低学历玩家「翻身」的主要路线，也是破产的主要路线。

**收入校准（新增断言）**：
- 全体成年人（按人头）的收入五等份边界，要贴近统计局 2024 年人均可支配收入五等份（9542 / 21608 / 33925 / 53359 / 98809 元）；
- 农民工路线的月收入中位数在 4500–5600 元（统计局 2024：月均 4961，外出 5634，本地 4291）；
- 城镇私营单位从业者平均年薪约 6.9 万，非私营约 12.4 万；IT 和金融最高（非私营约 23.9 万、20.2 万）；
- 同学历同城市的人，P90 / P10 ≥ 3 倍；90% 的人一生里至少有一次收入上涨 ≥ 30% 或下降 ≥ 30%。

### 4.4 钱：花钱与行动菜单

随时可开（6 岁起由父母出钱，18 岁起花自己的）：

| 类别 | 项目 |
|---|---|
| 孩子身上 | 补习班、兴趣班、择校费、学区房、国际学校、出国留学 |
| 自己身上 | 考证、学技术、健身、体检、旅游（国内 / 国外 / 和谁去）、买车 |
| 家 | 给父母寄钱、给父母看病、借钱给兄弟姐妹、给孩子付首付、彩礼 / 嫁妆 |
| 房 | 买房（老家 / 县城 / 省会 / 一线，小房子 / 正常房子）、房贷、提前还款、卖房、出租 |
| 理财 | 存银行、买基金、炒股、买理财（有暴雷风险）、**网贷（会接上赌博和债务剧本）** |
| 买彩票 | 每周 2 块，一辈子不中也算一种人生 |

**房子要能买得起**（V1 遗留问题：10 万局只有 72 人买房）：县城、老家房价低，首付门槛按真实比例。
校准目标是到 40 岁时城镇家庭住房拥有率在合理区间（待 Claude 补数据）。

### 4.5 关系与家庭

- **恋爱**：初恋（初中、高中）、大学恋爱、异地恋、分手；
- **相亲**：卡上写明对方的情况（工作、存款、有没有房），彩礼金额按地区（数字待 Claude 补，只陈述不评价）；
- **婚姻**：亲疏值；婚姻危机卡（争吵、出轨、婆媳）；离婚和分财产；
- **孩子**：可以有多个孩子（V1 最多一个）；谁带孩子（自己带 / 老人带 / 送回老家留守）；
  **鸡娃 vs 放养**：教育投入直接影响下一代的起点（接上家族接力）；
- **父母**：变老、生病（大病医疗自付，要不要卖房给父母治病）、养老（接来同住 / 养老院 / 兄弟姐妹轮流）、遗产；
- **兄弟姐妹**：借钱不还、分家、宅基地和拆迁款纠纷、一起照顾父母。

### 4.6 剧本库：人生百态（用户点名）

一个**剧本**是 2–4 张连环卡，跨越几个月到几年，每一步都要你选，后果会一直跟着你。
**案底是中国特色的长期后果**：留了案底，考公、参军会受影响，子女政审也可能被卡。

| 类别 | 剧本示例（括号里是分支） |
|---|---|
| **意外** | 车祸：你被撞（私了 / 走保险 / 打官司，可能留下伤残）；你撞了人（逃不逃，赔多少）· 工地摔伤（工伤认定 / 老板跑路）· 溺水救人 · 火灾 |
| **被侵害** | 电动车被偷 · 手机被抢 · 入室盗窃 · 被电信诈骗（刷单、冒充公检法、杀猪盘）· 被传销拉进去（逃出来 / 拉亲戚下水） |
| **越界** | 醉酒闹事（道歉赔钱私了 / 动手 → 拘留、案底）· 赌博（朋友带你打牌 → 小赢 → 越玩越大 → 借网贷 → 戒 / 卖房 / 家人跟你断绝来往）· 小偷小摸（少年时偷东西被抓 → 家长领回 / 进少管所）· 酒驾 |
| **江湖路**（不读书以后） | 跟着「大哥」混（收保护费、看场子 → 被抓 / 洗手开店 / 一直混到中年）· 网吧、游戏、电竞青训（极少数打上职业）· 当兵 · 南下进厂 · 学手艺 |
| **诱惑与陷阱** | 网贷 · P2P / 理财暴雷 · 「稳赚」的投资 · 保健品骗局（父母被骗）· 婚托 |

**发生概率**：能找到统计的用统计（交通事故、电信诈骗、离婚率、癌症发病……），找不到的标「参数」，
目标是每局平均触发 2–4 个剧本，**不能每局都狗血**。

**尺度：用户 2026-10-22 选「再大胆一点」**。在 V1 基础上放开：
- **家暴**：可以写（小时候目睹父母、婚后被打或者自己动手），写选择和后果（报警、告诫书、离婚、忍下去），附反家暴求助渠道；
- **坐牢**：完整写：看守所、判决、服刑、减刑、家人探视、出狱后找工作被拒、案底跟一辈子、子女政审受影响；
- **毒品**：被引诱 → 强制隔离戒毒 → 复吸或戒断，写后果；
- **赌博和高利贷**：可以一路写到卖房、离婚、被催收、跑路。

**硬红线（不变，写死在测试里）**：
- **不写方法**：不教怎么偷、怎么赌、怎么诈骗、怎么吸；
- **不美化**：混社会、赌博、吸毒的结局按现实比例，绝大多数是坏结局，「洗白成功」只能是少数；
- **不做性暴力**；涉及未成年人的暴力只写被害或旁观，不写细节；
- 自杀只写「离开了」并附热线；
- **不碰政治敏感**：不写上访、群体事件、强拆冲突、对政策和制度的评价；拆迁只写补偿结果；
- 首页提供「略过沉重情节」开关，打开后不出现犯罪、毒品、赌博、家暴、自杀、重病剧本；
- 只陈述，不给地域贴标签。

**风险提示**：尺度放大后，小红书限流和举报的风险会上升。分享卡上**永远不出现**犯罪、毒品、家暴字样（称号库里这类称号只在站内显示，分享卡换成中性说法）。

## 9. 补充反馈（2026-10-22 第二批，朋友试玩原作后的建议）

1. **好事坏事都要有**：剧本和卡池要平衡，好运、温暖、小确幸和坏事一样多，不能一路惨到底。校准：每局「好结局」剧本和「坏结局」剧本都至少各 1 个的比例 ≥ 60%。
2. **完整的婚恋线**：谈恋爱 → 分手 → 结婚 → 离婚 → 再婚，可以发生多次，**70 多岁也能再婚**（老年再婚、搭伙过日子）。
3. **伴侣资料卡**：每个恋爱 / 相亲 / 结婚对象都有一张资料卡：名字、年龄、籍贯、学历、职业、年收入、存款、有没有房车、性格、家庭情况（父母做什么、有没有兄弟、要不要彩礼）。
   选择之前看得到，这是「选人」的乐趣所在。
4. **婚姻过不去时也要有选择**：危机卡给出 忍下去 / 冷战 / 婚姻咨询 / 分居 / 协议离婚 / 起诉离婚。
5. **离婚按《民法典》来（朋友原话：我很有钱，我就不离婚，要分我的钱，不离）**：
   - 婚前财产归个人，婚后所得是共同财产，离婚分共同财产；
   - 协议离婚有 30 天冷静期，期间任一方可以反悔；
   - 一方不同意离婚：另一方只能起诉；第一次起诉通常不判离，分居满一年后再起诉应当判离（《民法典》第 1079 条）；
   - 所以玩家可以「拖着不离」，对方也可以起诉。和有钱人结婚再离婚能分到多少，取决于婚后共同财产，不是对方全部身家。
   - 彩礼：婚后很快离婚、没有共同生活的，按司法解释可能要部分返还（只陈述规则，不评价）。
6. **职业种类再多**：在 M2 的 30 个职业基础上明确加入：**自由职业**（设计、写作、摄影、翻译）、**医生**（规培、主治、副主任、主任）、
   **军人**（义务兵、士官、军官、转业）、**老师**（职称）、**服务员**、**保洁**、保安、厨师、护工、快递员、房产中介、保险销售、网店店主、律师、会计。目标 ≥ 40 个职业。
7. **彩礼分地区**：彩礼金额按省份和城乡不同（Claude 补数据，只陈述数字不评价地区）。相亲卡和婚礼卡显示当地大致行情，家里拿不拿得出来是一张卡。
8. 总原则再强调一次：**选择多一点才好玩**。
