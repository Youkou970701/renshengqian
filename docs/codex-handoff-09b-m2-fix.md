## 2. 收入一年一跳：门槛被噪声「刷」过去了（P0）

`sample-lives.json` 里的实际轨迹：
- 浙-2026-943206 当**教师**：10.9 万 → 11.3 → 14.3 → 8.4 → 12.3 → 7.8 → 11.2 万……同一份工作，没有任何事件，**每年上下跳 30–40%**。
- 冀-2026-083642 **互联网职员**：5.3 万 → 4.6 → 3.0 → 2.4 → 3.2 万，没被裁、没换工作。

现实里工资是有黏性的：同一份工作的年收入一般只有小幅波动，大起大落来自**事件**（升职、跳槽、被裁、失业、生意好坏、行业周期、生病）。
Claude 上一轮写的「90% 的人一生至少一次涨跌 ≥30%」本意是要这些事件，结果年度噪声也能满足，这是指标定义的漏洞。现在补上：

**新增门槛**（写死在探针里）：
- **同一份工作、同一职级、当年没有任何收入事件**的连续两年：年收入变化的中位数 ≤ 5%，P90 ≤ 12%；
  其中**体制内**（公务员、事业编、教师、医护、军人）P90 ≤ 6%。
- 销售、个体户、经营、网约车、主播这类**本身波动大的职业**可以放宽到 P90 ≤ 30%，但要在职业表里显式标 `volatile: true`。
- 原来的「90% 的人一生至少一次涨跌 ≥30%」改成：**只统计由事件引起的涨跌**，比例仍要 ≥ 80%。每次 ≥30% 的变化都要能在当年的事件日志里找到原因。
- 修完以后，收入五等份等原有门槛仍要通过。

## 3. 自动玩永远不开店（P1）

你在报告里写了：默认自动策略不会主动开办生意，所以经营系统只有手动玩家才看得到。可是中国有上亿个体工商户，开店、做小生意是很多普通人生的主线，
自动局、极速局、家族接力、每日签都要能自然出现。

- 自动策略按处境开店：有手艺、有积蓄、被裁、回老家、外出打工多年的人更容易开店。
- 新增门槛（status=参数）：活到 45 岁的人里，**一生中自己经营过生意（个体店、小厂、网店、补习班等）的比例在 8%–20%**；
  经营过的人里，关过店的 ≥ 40%（不能人人开店都成功）。
