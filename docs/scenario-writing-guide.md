# 剧本写作规范（Claude，2026-10-22）

范例：`src/content/scenarios-v2.js` 里 Claude 手写的 10 个剧本（醉酒、酒驾、赌博、少年小偷、混社会、帮信罪坐牢、车祸、被抢、丢电动车、拆迁）。
剩下由模板 `story()` 批量生成的约 50 个剧本，**M5 必须按本规范全部重写**，同编号写进 `scenarios-v2.js` 即可自动替换。

## 为什么要重写

模板版每个剧本的选项都是同一对「找可信的人一起商量 / 先整理眼下的事情」，两个选项后果几乎一样，结局只在最后一步掷骰子。
玩家感受到的是「看通知」，不是「做选择」。用户原话：「选择多一点才好玩」。

## 引擎能力（`src/engine/scenarios.js`，向后兼容）

| 选项字段 | 作用 |
|---|---|
| `exit: 'avoided' \| 'mixed' \| 'rehabilitated' \| 'bad' \| 'good'` | 选了就结束剧本，直接给这个结局 |
| `risk: ±0.x` | 累积到最后的结局概率：坏结局概率 + risk，好结局概率 − risk |
| `next: 步骤序号` | 跳到指定一幕（默认下一幕） |
| `delay: 年` | 下一幕隔几年发生（默认 1） |
| `waitForRelease: true` | 下一幕等到出狱以后 |
| `text` | 选完以后写进人生纪录的专属叙述（没有则记「你选择了「…」」） |
| `endText` | 这个选项结束剧本时的结尾 |
| 剧本级 `endTexts: { good, bad, mixed, rehabilitated }` | 按结局给不同的结尾 |
| 剧本级 `outcomeEffects` | 每种结局真正落到状态上的后果（案底、残疾、破产、断绝来往、离婚危机…） |

每一幕的正文和玩家的选择都会自动写进人生纪录。

## 写法

1. **第一幕给出「躲开」的出口**。能躲开的事（喝酒后动手、去赌、借银行卡、跟着混）一定有一个 `exit: 'avoided'` 的选项，配一句「后来听说……」的结尾，让玩家知道自己躲过了什么。
   躲不开的事（被撞、被抢、拆迁）就没有这个出口，但第一反应要有不同的选项（报警 / 私了 / 追上去）。
2. **每一幕至少两个后果不同的选项**。测试会检查：同一幕里不能有两个效果、风险、结局都相同的选项。
3. **选择通过 risk 影响结局，而不是写死结局**。「道歉调解」比「硬扛」的坏结局概率低，但不是零。
4. **具体**：写钱的数目、时间、地点、谁打来电话（「催收打到了你妈的手机上」好过「债务压力增大」）。第二人称，短句。
5. **结局分三档写**：`bad` 写付出的代价（判决、残疾、卖房、断绝来往），`mixed` 写事情过去了但留下了什么，`rehabilitated` 写改过以后的样子（代价仍在）。
6. **越界类不美化**：越界剧本里不能有 `good` 结局。门槛：没躲开的人中，实际承担严重后果 ≥ 60%，毫发无损洗白 ≤ 15%（`scripts/probe-m3.mjs`）。
   「刚沾边就收手」（向家里坦白、不再跟着去）记为 `mixed`；「出了事以后改过」才是 `rehabilitated`。
7. **未成年人**：可以是受害者、旁观者；唯一允许的越界是不涉及暴力的小偷小摸，并且写明「未成年时的记录依法封存」、不留刑事记录。
   未成年剧本的触发年龄要保证所有幕都在 18 岁以前走完（三幕就是 ≤14 岁开始）。
8. **法律细节写对**：醉驾（危险驾驶罪、吊销驾照五年内不得重考）、帮信罪、自首和认罪认罚从宽、未成年犯罪记录封存、伤情鉴定轻伤以上转刑事……写之前查清楚。
9. **红线**（`tests/scenario-content.test.js` 写死）：不写作案、赌博、吸毒、逃避检查的方法；不写性暴力；自杀只写「离开」；不碰上访、群体事件、强拆冲突、政策评价；
   拆迁只写补偿和之后的选择。

## 温暖类剧本（28 个）

也要重写成有选择的：例如「多年后的道谢」可以选 去见他 / 回一条消息 / 不回；「老家的门又开了」可以选 回去 / 寄钱请人修 / 卖掉老屋。
好事也要有取舍，选择才有意义。
