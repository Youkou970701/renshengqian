# Codex 交接 09d：M5 裁定（好坏双覆盖口径 + 称号传记打磨），然后完成 M5 收尾

> M4 复验通过。M5 重写了全部 51 个模板剧本、新增 4 个，其余 12 项剧本门槛、收入、教育分层都过了；停在「好坏双覆盖 49.4%」也是对的。
> 你说「不把 avoided 或 mixed 改名凑数」，这个立场是对的。下面是 Claude 作为规格制定者对**口径**的裁定，不是改名。

## 1. 好坏双覆盖：口径裁定（Claude 实测诊断）

Claude 按类别拆了 1500 局的剧本结局：温暖类 92% 是好结局，没问题；下降来自**负向剧本**——有了「躲开」出口和「中性」结局后，
被抢 52% 是 mixed（手机没追回）、车祸 50% 是 mixed（养伤半年），这些都不算 `bad`。于是「有坏结局」的人生只剩 56.5%。

这条门槛来自用户朋友的反馈「好的元素不好的也要有」，本意是**人生里既有顺心事、也有挫折**。被抢、车祸养伤半年当然是挫折，只是不到「严重后果」那一档。
旧口径把「挫折」等同于「严重后果」，是 Claude 当初定得不准。新口径：

- **经历过坏事** = 负向剧本（`positive:false`）里坏事真的发生了：结局为 `bad`、`mixed` 或 `rehabilitated`。**`avoided`（躲开了）不算。**
- **经历过好事** = 正向剧本（`positive:true`）拿到 `good`。
- 门槛数值 60% 不变。Claude 用当前候选代码实测：新口径双覆盖 **65.0%**（有好事 83.0%、有坏事 74.4%，3000 局）。

改 `scripts/probe-m3.mjs` 的这一项（名称改为「每局经历过好事和坏事各至少一次 ≥60%」，在注释里写明口径和本裁定）。**「越界严重后果 ≥60%」那条仍按严重后果算，不受影响。**

## 2. 称号与传记打磨（M4 复验时读出，不卡门槛，M5 一起修）

Claude 读了 10 个随机终局，比上一版好很多（顺序对了、「父母离婚」「初中没读完」直说了，「考了 14 次公务岗位仍未录用的人生」很有力）。剩下：

1. **挑重点**：「从助理技术员干到技术员的人生」只升一级、「在 41 岁办完手续继承一笔遗产的人生」重点在办手续——都不是这一生最突出的事。
   - 职级称号只在**跨越 ≥2 级或到达职业顶级**时才有资格当主称号；
   - 继承、结婚这类称号写结果不写手续：「四十一岁继承了一笔遗产的人生」。
2. **去公文腔**：称号和传记里不用「办完手续」「登记结婚」（写「结婚」）、「公务岗位」（写「公务员」或「考公」）、「结束在岗工作」（「退休」已经够了）、「编辑写作者」（写「编辑」）。
   把这些加进 09c 建的「生硬表达」清单。
3. **小数字写汉字**：「开过 1 次生意关了 1 次门」→「开过一次店又关了的人生」。十以内次数写汉字；年龄、金额可以用阿拉伯数字。
4. **传记只写人生大事**：教育结束、工作变动、结婚离婚、孩子、重要剧本（负向剧本和好运剧本）、退休、离开。
   **温暖类小事不进传记**（「47 岁归还借来的伞」「58 岁收拾出窗边书桌」），它们留在人生纪录里就好。
