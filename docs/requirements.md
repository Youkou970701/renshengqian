# 需求确认单：投胎模拟器 · 中国版

> 立项日期：2026-10-21
> 状态：**已拍板，待 Codex 开工**
> 缘起：用户玩 [80亿分之1](https://1in8b.life/zh-hans/)（172 国随机出生的人生模拟），连玩几局「没有一个读上大学、全是辍学、考不上高中」，
> 又气又上头。决定做一个**中国版**，素材发小红书。分工：**Claude 写 `docs/` 和 `data/`，代码一律 Codex 写**。

---

## 原作拆解（Claude 2026-10-21 实玩一局：巴基斯坦俾路支农村男孩，玩到 44 岁）

| 机制 | 原作做法 | 我们学不学 |
|---|---|---|
| 出生抽签 | 按各国年出生数加权抽国家，再抽城乡、家境五分位、父母职业、宗教 → 「出生登记卡」 | **学**，换成省份 × 城乡户口 × 家境五分位 × 父母职业 × 是否留守 |
| 对照 | 出生卡上和「你实际出生的地方」并排比（寿命/夭折/受教育年数/GDP） | **学**：和「你自己的省份」比 |
| 时间推进 | 约 1 小时活完一生，1 年≈55 秒，1–16 倍速 | **改短**：默认约 10 分钟，可调 5/10/20；用户反馈原作「玩得眼睛困」 |
| 属性 | 健康 / 幸福 / 知识 / 人际 0–100 + 净资产 + 年收入 | 学，加一项「卷度」（努力），见下 |
| 每年重心 | 6 岁起每年选：学习/工作/家人/健康/兴趣… | 学 |
| 重大抉择 | 升学、工作、买房、创业、恋爱、移居；可「自动抉择」带倒计时 | 学，换成中国节点（中考、高考志愿、考研/考公、相亲彩礼、买房、35 岁…） |
| 统计脚注 | 每条人生事件下附真实统计 + 出处（「巴基斯坦高中完成率约 27%（UNESCO）」） | **必学**，这是质感来源，也是小红书截图的信息量 |
| 残酷感 | 选了「升高中」照样被判「家里筹不出学费，只好放弃」——选择只微调概率 | **必学**（用户明确要保持残酷感） |
| 同秒出生 | 另外 4 个同秒出生的人在旁边并行活完 | 学：同一秒在中国出生的另 4 个人（大概率不同省） |
| 人生地图 | 一格一年的格子图，颜色=幸福度；存活曲线 | 学 |
| 停顿反思 | 5/15/30/50/70 岁停下问一个问题，可留一句话 | V2 |
| 重内容 | 死亡、暴力、自杀按统计发生，不描写画面，附求助渠道 | 学，但收敛（见红线） |

**不扒原作代码和文案**，只学玩法；统计数据自己整理（`data/cn-stats.json`）。

## 成功标准

1. 手机竖屏和电脑都能玩，**手机优先**（小红书用户 90% 在手机上）。
2. 一局 5–20 分钟可选，**中途关掉能续**（localStorage）。
3. **残酷但讲道理**：10 万局蒙特卡洛的群体结果要贴合真实统计（普高率≈61%、出生队列本科率在合理区间、985≈1.5–2% 等），
   每条「命运裁决」都能追溯到一个统计数。这是验收的硬指标，不是看着像就行。
4. 两张**能直接发小红书的卡片**：出生卡、人生终局卡（9:16 竖图，一键存图）。卡上要有一个扎心数字
   （「同省同年出生的 100 个人里，有 34 个读了本科。你不在其中。」）。
5. **出生编号可复现**：同一编号 = 同一出身 + 同一随机序列。评论区「晒编号」就是传播钩子。
6. 设计要**酷**（用户原话），不能是白卡片+圆角的「AI 味」模板。见「视觉」。

## 这次要做（V1）

### 出生（抽签）

按 `data/cn-stats.json` 抽：
- **省份**：按各省出生数加权。
- **城乡户口**：按省份档位的 urban_share 浮动；农村出生比例全国约 40%。
- **家境五分位**：城乡条件分布（农村偏下、城市偏上，Codex 定参数，过校准测试）。
- **父母**：年龄、学历、职业（农民/外出务工/个体/工人/教师/公务员/白领/老板…，与家境相关）。
- **留守**：农村出生时按约 37.7% 概率父母至少一方外出（数据待核）。
- **独生/兄弟姐妹**、性别（出生性别比约 110:100，待核）。

### 人生阶段（中国节点）

| 年龄 | 节点 | 残酷来源（统计驱动） |
|---|---|---|
| 0–5 | 夭折风险、留守、隔代抚养 | 婴儿死亡率 4.0‰；留守概率 |
| 6–15 | 小学、初中；每年重心；成绩分位 | 义务教育巩固率 95.9%：约 4% 读不完初中 |
| 15 | **中考分流** | 全国普高率约 61%；城乡、家境、省份档位强相关；贫困农村读完高中仅约 37% |
| 18 | **高考** → 985 / 211 / 普通本科 / 专科 / 落榜（可复读一次） | 省份档位本科率 36%–70%；985 约 1.6%；北大农村生源约 14% |
| 18–22 | 中职/专科路线：进厂、专升本 | |
| 22 | 考研 / 考公 / 就业 / 回老家 | 考研报录约 24%；国考约 86:1；青年失业率 16.5% |
| 25–35 | 城市选择（一线/省会/县城/老家）、相亲、彩礼、结婚、买房、生娃 | 房价收入比、初婚年龄约 28.7、总和生育率约 1.0 |
| 35 | 「35 岁」：裁员、转行、外卖/网约车 | 参数化 |
| 40–60 | 父母养老、孩子中考（**下一代复读你的命运**——孩子的出身=你的终局） | |
| 60+ | 退休、养老金城乡差、疾病 | 城乡居民养老金 vs 职工养老金 |
| 死亡 | 按省份 × 性别预期寿命抽 | 2024 全国 79.0 岁；西藏等明显偏低 |

**「努力」的权重**：每年重心选学习会提高成绩分位，但**上限受出身约束**——这是原作的核心，保留。
玩家能把 30% 的概率拉到 40%，拉不到 90%。机制参数写在一个文件里集中调。

### 界面

- 首页：标题 + 一句钩子 + 「投胎」大按钮 + 可选「你出生在哪个省」（用于对照，只存本机）+ 时长 5/10/20 分钟。
- 出生卡 → 「开始这一生」。
- 主界面：年龄大字、四属性、人生纪录流（每条附统计脚注）、同秒出生 4 人状态、暂停/倍速/自动抉择。
- 抉择弹层：2–4 个选项，每个选项标出影响的属性，自动抉择带倒计时。
- 终局：人生地图格子 + 关键数字 + 「同省同年 100 人里你排第几」+ 存终局卡 + 再投一次。
- 统计出处页：列出全部数字和来源（数据可信度就是传播力）。

### 视觉（用户：「设计酷一点」）

不定死，**02 阶段出 4 个方向的 design-lab 让用户选**。候选方向：
1. **人事档案**：牛皮纸档案袋、红色公章、户口本内页、打字机等宽字体。出生卡=户口登记页，终局卡=档案封存页。
2. **开奖机/摇号**：黑底、荧光数字滚动，出生像彩票开奖，同秒出生的人像摇号机里的球。
3. **城市夜景像素**：深色像素画，城乡场景随人生变化（原作是浅色像素，我们做深色霓虹，拉开差异）。
4. **数据新闻**：极简黑白 + 一个强调色，大字号统计数字，像财新/端传媒的数据报道。

硬约束：手机 375px 宽可用、9:16 卡片在小红书缩略图里也能看清主数字、不用 Google Fonts 等境外 CDN。
**用户 2026-10-21 看了朴素版说「全黑不好看」**→ 不再默认深色；03 出 5 个方向（档案 / 车票 / 摇号机 / 数据新闻 / 竖版长卷），深色最多 2 个。

## 这次不做

- 登录、排行榜、评论、在线人数（纯静态站，不要后端）。
- 「过去的世界 / 未来的世界」（V1 只做「现在的中国」）。
- 多语言、全球版。
- 5/15/30/50/70 岁停顿留言（V2）。
- 音乐。

## 决策与假设

| # | 决策 | 依据 |
|---|---|---|
| 1 | Vite + React 18 + JavaScript，纯前端；部署 Cloudflare **经典 Pages**（pages.dev） | 国内 workers.dev 打不开、pages.dev 能（实测） |
| 2 | 全部统计在 `data/cn-stats.json`，Claude 维护；机制参数在 `src/engine/params.js`，Codex 维护 | 数据和手感分开调，数据改动可追溯 |
| 3 | 随机数用可种子化 PRNG（如 mulberry32），**引擎禁用 `Math.random`** | 出生编号可复现 + 测试可重放 |
| 4 | 引擎是纯函数：`step(state, choice, rng) → state + events`，零 DOM | 才能跑 10 万局校准、出对抗样本 |
| 5 | 事件文案用模板库（`src/content/events/*.js`），每条事件带 `stat` 字段指向 cn-stats 的键 | 脚注可追溯；改文案不碰引擎 |
| 6 | 存图用 `html-to-image` 之类在前端生成 PNG，不上服务器 | 零后端 |
| 7 | 暂名「投胎模拟器」，目录 `toutai-sim/` | 待用户确认名字，不阻塞 |

## 红线（小红书平台 + 我们自己的底线）

1. **只陈述统计，不评价政策**。不出现针对户籍、高考、计划生育等制度的评论性文案；事实句 + 出处。
2. **自杀、家暴、性暴力**：V1 只保留疾病、意外这类死亡；自杀按统计发生时只写「在 X 岁离开了」，
   不写方法、原因，同屏显示心理援助热线（号码上线前 Claude 再核）。不做性暴力事件。
3. **不出现真实人名、真实学校以外的真实机构的负面描述**；学校只用「985」「本地二本」这类泛称，不点名。
4. 不做地域歧视文案：省份差异只用数字说，不给省份贴标签。
5. 页面注明「基于公开统计的模拟，不代表任何个人命运」+ 15 岁以上。

## 已知风险

1. **省级数据大半是估算**（见 cn-stats.json 的 status），上线前 Claude 用《中国统计年鉴2025》补核。不阻塞开发。
2. 残酷感 vs 留存：全是辍学会让人关掉。校准目标就是**真实分布**——城市中产孩子大概率上本科，
   这样「抽到好签」的人也会有，截图对比才有张力。
3. 小红书限流重内容；卡片文案避开「死」字可用「离开」「终局」。

1. **01 引擎 + 校准**：数据加载、抽签、全生命周期引擎、事件库首批、10 万局校准测试、一个能玩通的朴素界面。
