## 1. 硬约束（所有方案都要满足）

1. **用真数据**：每个方案用同一套引擎跑同两个编号，一个是城市 Q5（`京-2026-066321`），一个是农村 Q1 留守（`粤-2026-694669`）。
   design-lab 可以 import `src/engine/`，也可以预先导出 JSON。不准写死假文案。
2. **每个方案出 3 屏**，都要有 375×812 手机版和 1280 宽桌面版：
   - **出生卡**（投胎结果揭晓的那一刻，这是第一个截图点）
   - **主界面·人生中段**（例如 15 岁中考裁决弹层正在显示；人生纪录流、属性、同秒出生 4 人都要在）
   - **终局卡 9:16**（1080×1920 导出尺寸，要发小红书的那张）。缩成小红书双列缩略图（约 170px 宽）时，**主数字和一句话还要看得清**。
3. **字体不能用 Google Fonts 或任何境外 CDN**，pages.dev 在国内要能打开，Google Fonts 在国内加载不了。
   要么用系统字体栈，要么自带开源字体的子集（霞鹜文楷、思源宋体/黑体、站酷系列等，**先核 License 能否商用、能否网页嵌入**，写进 results）。
4. **不要全黑**（用户明确不喜欢）。深色方案可以有，但 5 个里最多 2 个以深色为主，而且深色也要有明确的色彩个性，不能是灰黑加白字。
5. 禁用 AI 默认款：白底圆角卡片一张张往下堆、渐变背景、毛玻璃、柔和大阴影、emoji、紫蓝科技风、发光效果。
6. **和原作拉开差异**：原作 80亿分之1 是浅米色纸张 + 酒红色 + 横版像素小场景。我们任何方案都不要做成「米色纸 + 酒红 + 横版像素」的组合。

## 2. 5 个方向

每个方向要做深，不是换个配色。下面是方向说明，具体怎么做你来设计。

### A. 人事档案
牛皮纸档案袋、户口本内页的格线和栏目、红色公章、打字机等宽字体。
出生卡就是「常住人口登记卡」的版式（姓名 / 出生地 / 户别 / 父母……），关键裁决像在档案上**盖章**：
「普通高中 · 未录取」是一枚斜着压下去的章。终局卡是档案封存页，盖「归档」章。

### B. 车票
人生是一张火车票。出生卡就是一张蓝色（或红色老式）车票：始发站是出生地，车次是出生编号，座位等级对应家境。
每个人生阶段是一个经停站。中考、高考是「换乘」，没录取就是「改签」。终局卡是「终到站」，
同秒出生的 4 个人是同一班车上的另外 4 张票，各自在不同站下车。春运、打工、回乡这些都和车票天然相关。

### C. 摇号机
投胎就是摇号。深色底配一个强烈的单色（荧光橙或信号绿），出生时数字和省份名像开奖机一样滚动后停下。
同秒出生的人是摇号机里的球。属性用机械计数器或七段数码管显示。
**这是两个深色名额之一，要做出色彩个性。**

### D. 数据新闻
像财新、端传媒、The Pudding 的数据报道。白底、强网格、一个强调色，超大号数字。
「100 个和你同省同年出生的人」用 100 个小方块（点阵）表示，你是其中高亮的那一个，每个节点淘汰一批方块变灰。
终局卡就是这张点阵图配一句话，这个最适合小红书。

### E. 竖版长卷
手机竖屏往下滑，人生是一条从上往下的长卷或时间轴：村口、镇中学、县城、工厂或写字楼……
场景插画或几何化的块面随城乡和职业变化。和原作的横版像素小场景要明显不同：竖向、块面或剪纸、不用像素。
可以做浅色，也可以是夜景。

## 4. 文案小修（顺手做，02 日志里读出来的）

1. 「爸爸周建华当时32岁，**做外出务工者**」读起来生硬。职业名词要放进自然句式：
   「在外地打工」「在镇上开小卖部」「在县医院当护士」。每个职业配一个**动词短语**，不要用「做 + 职业名」。
2. **机制参数不显示脚注**。35 岁那条脚注写的是「本次人生计算中……风险为 14%。来源：本地岗位风险参数；不是行业调查结果」，
   这是写给开发者看的，玩家不需要。规则：只有 `data/cn-stats.json` 里 status 为「已核」或「待核」的统计才渲染成脚注；
   参数驱动的事件不显示脚注。
3. 脚注里的免责尾巴要收短。「这是一项历史统计」「年份较早，不代表今天每个家庭的情况」「这是人口平均指标，不是个人寿命期限」：
   这些放进统计出处页统一说一次。脚注本身只保留「数字 + 年份 + 来源」。
4. 「这一段学业没能完成」太含糊。18 岁辍学要写出是哪一段：「高三没读完，你跟着同乡去了东莞」。

改完重新跑 `npm test` 和 `npm run calibrate`，结果要和 02 一致（文案改动不能影响机制）。
