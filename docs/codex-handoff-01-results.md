## 交付与运行

## 纯函数与复现约定

step(state, input) → {state, events}。随机数状态保存在 state.rngState；random(seed) → {value, seed} 没有闭包游标。编号以安全整数编码完整省份、年份与六位编号，PRNG 使用其哈希。引擎不调用环境随机数、时钟、DOM 或 React。

input.focus 省略表示自动安排，显式值 study/work/family/health/hobby 表示玩家重心；input.choice 为 pending 的选项 ID；input.auto=true 使用确定性自动选项。pending 未决时不会推进；结算 pending 不推进年龄。**选择序列包含年度重心和重大抉择**。同一编号、同一完整输入序列，在同一引擎和底表版本下事件日志 JSON 完全相同。自动抉择与手动抉择保留相同的一次随机消耗。capture=false 仅省略日志与格子，测试证明不会改变机制结果。

- stageBase=2.442347035，generalBase=0.676886660：分别从92%高中阶段进入锚点与61%普高/92%进入比值做 logit 反解。
- completionWealth 与 completionBase=3.960807487：联合约束农村Q1从出生算37%完成，以及机制锚点“高中阶段进入者85%完成”；后者用于满足最终本科队列28–40%与考试录取37–45%的联合区间，不冒充已核事实。
- bachelorBase=0.099330796：保持省档底表 logit 相对差异，对全国高考者41.5%内点目标二分拟合。bachelorGrade 与 bachelorGrind 以标准化学习暴露梯度比约0.494:1绑定，联合解出同出生队列约12pp努力收益；完整生命周期再验收5–20pp区间。
- eliteUrban 与 eliteBase=-4.772874869：按985总体1.6%和农村生源17.5%代理中点联合二分拟合；211累计率基准=-3.577828578，拟合底表5%（包含985），采用嵌套录取阈值避免重复计数。
- 其余未识别的 β **显式置零**（stageWealth/generalWealth/bachelorWealth/bachelorUrban/careerWealth/careerGrade/careerGrind）。现有汇总表无法唯一识别每个节点的财富、户口、成绩、努力独立效应，因此采用最小复杂度约束，不能声称这些0或非零β是中国社会的因果估计。出身差异仍通过城乡家境条件分布、农村Q1毕业约束、省份档位和985城乡代理产生。
- 农村出生偏移=-0.007563243，求解全国40%出生农村占比；城市家境权重由总体每Q20%与农村权重反推，为 [0.13333333333333336,0.16666666666666669,0.2,0.23333333333333336,0.26666666666666666]。父母、性别与兄弟姐妹分布的缺数部分保留机制先验。
- Gompertz-Makeham 按省×性别求解尺度以匹配预期寿命；婴儿和1–4岁风险单独匹配底表，最大110岁必终止；逐省逐性别期望误差测试<1e-8。健康属性当前不改变死亡风险，避免未经重新校准破坏寿命边际。
- 工资/房价/养老金/储蓄率、35岁风险、专升本基准0.06等为集中在 params.js 的**机制估计**；不称已核统计。专升本只改最终本科队列，不冒充首次高考本科录取。

## 数据疑问

1. 高中阶段毛入学率92%与“初中毕业者进入高中阶段92%”分母不同。本次遵照交接验收映射，正式发布应核准。
2. 贫困农村37%为较早历史调查，与当前出生队列、省份档位拼接；不能理解为2026年儿童真实未来预测。
3. 985农村10–25%使用北大2013/2014生源做代理，非全体985。17.5%是产品校准内点，不是新的已核统计。
4. 各省本科率为报名者口径且底表混用年份，出生队列最终率另经模型推导；当前队列33%左右应由Claude判断，不能用报名者本科率直接替代。
5. 家境五分位与贫困Q1不是同一实际定义；城乡条件分布、父母学历职业、出生性别比、独生概率缺全国一致口径，本阶段均为机制设定。
6. 农村出生40%与省份urban_share是出生/户口/常住城镇化混合代理；拟合偏移只保证总体边际，不证明各省户口分布已核。
7. career.guokao_ratio_2026来源写“截至10/24”，晚于当前2026-10-21，未使用；使用2025的86:1。
8. 留守37.7%来自2013年，婴儿死亡、五岁前死亡、婚龄等待核标记仍保留。省份出生估算合计须归一化，不声称等于954万。
9. 生命周期为用当前截面统计构造的合成队列；死亡风险未因未来医疗趋势、个人健康重心而改变。寿命男女差为估算，最高年龄截断是机制。
10. 缺少可用于工资、养老金、婚姻选择成功率、房价收入比、35岁行业裁员、死因和职教升本的统计。相关机制已标注估计，正式上线前宜补表，不能把挂接的背景脚注当作这些具体概率的证据。
11. 当前不能从汇总率识别所有β，暂以未识别系数为0；有分层数据后再联合拟合，不能为了让数值“看起来完整”补造系数。
