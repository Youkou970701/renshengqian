# 交接 13：上线后的打磨结果

2026-10-28。基线为用户已验收上线的 `9768daf`。本轮只写本结果文档，`data/` 只读，不部署；未访问原作代码或文案。

## 本轮修改

1. 普通卡的纪录采用「当时实际显示的变体标题——你选了『选项』」，同时保存 cardTitle/choice 元数据。剧本沿用已记录的完整情境，仅记录一次选项，不重复标题和正文。中职入学结果改写为「你进入中职的……方向学习」，避免混入无上下文的选择句。
2. 确定性分配给名，覆盖主角、父母、兄弟姐妹、孩子、好友、伴侣与旧伴侣，包括逝者；同姓异姓都避开同一给名。补齐历史和未来出生年份。原随机流调用次数不变。旧存档重复姓名保留历史文字，下一次实际推进记录一次名字区分说明，面板与往后事件使用稳定的新称呼。
3. 亲疏原因写清谁做了什么、对方怎样回应。66 个社会选择的原因写入实际人名，例如「你没有把身份证借给胡语禾，对方有些不高兴」。6 条旧抽象短语加入生硬表达清单。
4. 钱面板以整元显示，去掉「金额取整」行；显示尾差并入已有最大来源，使整元行合计对齐净变化，内部真实账目仍保留精度。只有 ±1 元内部尾差而无实际收支时显示「净资产基本持平」，不伪造收支来源。排名改为「你的收入比全国约 N% 的同龄人高」「在出生省同龄人中排在前 N%」；样本和方法说明移至统计出处页。
5. 自由职业的长期「接单新人」按年资显示为「独立接单者 / 接单老手」；其他岗位长期未晋升时省去不合时宜的学徒、见习标签，不编造资格、职级、收入或晋升。
6. 幸福保留基础心情，叠加当期收入、健康、亲疏、失业与债务的影响。每次按当前处境重算，负债不会逐年重复扣分；选择、借还款、复工后及时更新，同年龄历史格同步更新，旧档可延续；旧纪录不追写新情境，首次继续推进或操作后应用新幸福。收入影响有上限，健康与关系各自发挥作用，失业与债务增加压力，不把所有困难年份压成 0。

## 13a：区分房贷、助学贷款与坏账

2026-10-28。按 `codex-handoff-13a-debt-happiness.md` 修正幸福的负债部分；上文 13 的表格保留为历史验收记录，负债门槛以本节为准。其余五项打磨保留，不改 `data/`，不部署。

### 计算规则

- **正常房贷**：用合同月供除以当前月收入。占比 ≤30% 扣 0–3 分，随占比线性变化；30–50% 扣 5–10 分；>50% 扣 12–18 分。没有收入、当年已经结算但实付不足、或到期仍未还清，转入坏账压力；该房贷不再重复扣正常房贷分。刚买房尚无还款记录不算断供。旧标量房贷按原贷款重建规则推算月供，不改合同或实际结算。
- **助学贷款**：正常本金扣 2–5 分；存在 `loanInterestArrears` 时扣 8 分，不按网贷处理。
- **坏账**：网贷、赌债、剧本欠款、经营借款、现金缺口，以及上述断供房贷，按坏账金额相对收入扣 20–32 分。现金缺口取实际可用现金 `assets<0`，不拿投资余额抵消；正常房贷和助学贷款本金不会被并入这一项。

基础心情、收入、健康、亲疏和失业的原计算保留。每次重新计算当前处境，仍不会逐年重复累减；还款与复工后可恢复。旧幸福状态继续沿用原 `baseMood`，只替换处境分解，不把旧负债扣分留进基础心情。
