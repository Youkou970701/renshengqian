### 已定位的阻塞原因

1. **替代路线卡在中考之前弹出。** school-alternatives 的 priority=110，高于 school 的100；when 缺少「中考已结算且未进公办」这一前置条件。实际顺序变成「替代路线 → 中考」，自动策略看到尚未结算的 stage=false，全部选择工作，之后才进行中考。
2. 3000 局诊断中，替代卡提前出现 **2871 次**，没有一次是在中考结算后；这2871次均选择 work。真实公办未录取者1295人，也都没有判定后的替代卡。因此 probe.json 的 public/work 分布**不能当作合格的替代去向分布**：公开记录原始失败结果，同时附单独的顺序诊断，不包装成两条有效替代路线。
3. 普高原始入学参数为给民办/艺体等渠道预留容量而下调，但补充路线没有按正确顺序落地，导致实际普通高中率只有54.124%，低于58%下限。
4. 备考从「每年重新选择」改成一次进入后的持续状态，终身进入招录路径的人群随之改变，35岁前体制内比例降至2.536%，低于3%下限。不能沿用旧默认策略后宣称新系统已经校准。

诊断证据：[route-diagnostic.json](../tests/artifacts-09/M1/route-diagnostic.json)。复现示例鲁-2026-970772：15岁先出现替代卡（中考尚未结算、stage=false，选work），随后才出现school卡（选general）。**本轮按门槛失败停止，未在失败后继续修复或推进。**

### 1. 剧本：从「看通知」改成「做选择」

**问题**：60 个剧本由同一个模板 `story()` 批量生成，**每个剧本的选项都是同一对「找可信的人一起商量 / 先整理眼下的事情」**，两个选项后果几乎相同，结局只在最后一步掷骰子。
醉酒闹事第一句就是「你一次醉酒闹事伤了人」，动不动手不让玩家选；赌博一路直通卖房。数量门槛过了，但用户要的「选择多一点」完全没有体现。

**引擎**（`src/engine/scenarios.js`，向后兼容，原模板剧本不受影响）：选项新增 `exit`（提前结束，含新结局 `avoided` = 躲开了）、`risk`（累积改变结局概率）、
`next` / `delay` / `waitForRelease`（跳转与间隔）、`text`（选后叙述）、剧本级 `endTexts`（按结局给结尾）。每一幕的正文和玩家选择现在都写进人生纪录（原来纪录里只有「这段经历还没有结束」）。

**内容**：新文件 `src/content/scenarios-v2.js`，Claude 手写 10 个，同编号替换模板版：
醉酒闹事、酒驾、赌博（牌局→大场子→借款软件→催收）、**少年小偷小摸（新，12–14 岁，未成年记录依法封存，不留刑事记录）**、混社会、
坐牢（改为现实中年轻人最常见的「出借银行卡 → 帮信罪」全流程：看守所、认罪认罚、判决、服刑探视、出狱求职被拒）、车祸（私了 vs 报警定责）、被抢手机、丢电动车、拆迁（补偿到账后的三种用法）。
剩余约 50 个模板剧本由 Codex 在 M5 按 `docs/scenario-writing-guide.md` 重写。

**测试规则的修改（Claude 的决定，理由写在测试注释里）**：
- 旧规则「越界剧本每个最终选项坏结局 ≥65%」会让「道歉调解」和「硬扛」结局几乎一样，选择失去意义。改为**按随机选择真实走剧本**：越界不能有好结局；没躲开的人里严重后果 ≥40%、改过 ≤35%（单剧本层面）。
- M3 探针口径修正：分母只算**没躲开的人**（躲开了自然没有坏结局）；「严重后果」看实际承担的案底 / 残疾 / 破产 / 断绝来往，不看结局标签；「洗白」= 改过且没有付出严重代价。**门槛数值 60% / 15% 不变。**
- 未成年人：可以是受害者、旁观者；唯一允许的越界是不涉及暴力的小偷小摸。混社会因含暴力情节，改为 18 岁起。
- 新增测试：手写剧本每一幕不能有两个后果完全相同的选项。

### 2. 婚恋频率：原来几乎离不了、也再婚不了

**问题**（门槛没覆盖到，Claude 补）：3000 局只有 82 次离婚、6 人结过两次婚——结过婚的人里离过婚的约 3%，离婚的人里再婚约 9%。
根因：①23 岁以后再也没有「认识新的人」的卡；②婚姻危机卡有「当年没出过其他卡」的限制，且要和大量卡按权重竞争，每年情境卡抽取率仅 18%，实际被稀释到几乎不出现。
