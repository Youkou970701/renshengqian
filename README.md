# 投胎模拟器 · 中国版

**在线玩：https://toutai-sim.pages.dev**

出生是一张签。按各省真实出生人数，你会随机投胎到中国某个省、某个城乡、某种家境的家庭，
然后按公开统计一年一年过完一生：中考分流、高考、考研考公、相亲彩礼、买房、35 岁、父母老去。

你可以每年选择努力的方向，但关键关口由「命运骰子」裁决：揭晓前会告诉你录取概率，
以及家境、城乡、省份、成绩各自把它拉高或拉低了多少。

玩法灵感来自 [80亿分之1](https://1in8b.life/)。本项目只借鉴玩法，代码、文案和数据全部独立完成。

## 玩法

- **投胎**：5 / 10 / 20 分钟过完一生，中途关掉可以续玩
- **命运骰子**：中考、高考、考公等关口亮出概率和影响因素，「只差 1.4%」
- **一分钟极速局**：只看关键节点，一分钟一生
- **家族接力**：死后接着做你的孩子，看三代人能不能走出村子
- **每日一签**：同一天所有人拿到同一个出生，比谁过得更好
- **人生图鉴**：点亮 31 个省份，收集稀有成就
- **出生编号**：如 `粤-2026-694669`，同一编号 + 同样的选择 = 完全相同的人生

## 数据从哪来

统计底表在 [`data/cn-stats.json`](data/cn-stats.json)，每个数都标了出处和可信度：

- `已核`：有原文出处（国家统计局、教育部统计公报、国家卫健委等）
- `估算`：按公开数推算，待用《中国统计年鉴》补核
- `参数`：游戏机制参数，不是统计数

模型用 10 万局蒙特卡洛模拟校准，群体结果要对上真实统计（普高率约 61%、高考本科录取约 37–45%、
平均寿命约 79 岁等），同时按「省份档位 × 城乡 × 家境」分层检查。运行 `npm run calibrate` 可复现全部 25 项校准。

**这是基于公开统计的模拟，不代表任何个人的命运。** 适合 15 岁以上。

## 本地运行

```bash
npm install
npm run dev        # 开发
npm test           # 测试
npm run calibrate  # 10 万局统计校准
npm run build      # 生产构建，输出到 dist/
```

纯前端（Vite + React），没有后端，所有存档只保存在本机浏览器。
